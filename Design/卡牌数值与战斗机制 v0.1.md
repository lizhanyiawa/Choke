## 1. 属性系统

### 1.1 九属性

**金 / 木（毒）/ 土 / 冰 / 火 / 雷 / 光 / 暗 / 物理**

- 「木」与「毒」合并为一个属性：木系承担中毒、藤蔓、生长类效果。不单独开毒系，否则会多出一个只会上 debuff 的死属性。
- 「物理」是**中立属性**：不参与相克环，不吃克制加成，也不被任何属性克制。
- 因此实际参与相克的只有 **8 个**，物理是第九个"外挂"。

### 1.2 相克环

```
金 → 木 → 土 → 冰 → 火 → 雷 → 光 → 暗 → 金
```

| 关系 | 修正 |
|---|---|
| 顺时针第 1 位 | **+25%** |
| 顺时针第 2 位 | +10% |
| 逆时针第 1 位 | **−20%** |
| 逆时针第 2 位 | −10% |
| 同属性 | −10% |
| 物理 ↔ 任意 | 0 |

> **同属性 −10% 不是配队限制。** 真正对阵的是**队伍**，卡牌只是队伍里的组件 —— 7 人队塞 5 个火系完全可以。
> 你要担心的不是自家人打自家人那 −10%，而是对面那一队冰系会把你整队打穿。
> 克制关系在队伍层生效，所以它约束的是"这场仗怎么打"，不是"这个队能不能组"。
> 8 环的好处是每个属性都有 1 个克制方、1 个被克方、2 个邻居、4 个中立位 —— 长期加内容不需要重构。

**物理的例外**：目标是「灵体 / 无属性」时，物理 +20%。这样物理不是一个"永远中立的废属性"。

**属性挂在技能上，不挂在职业上**

| 项 | 规则 |
|---|---|
| 卡面 | **不标属性**。一张卡的 1–2 个技能各自带属性，不带的按物理 |
| 判定 | 克制看**这一次伤害的属性**，不看这张卡是什么职业 |
| 卡池 | 卡池 = 职业 × 品阶，**不会裂变成 14 × 9** |
| 例 | 缚术师可以有火缚 / 冰缚 / 雷缚三张卡，差的只是技能属性与 DOT 类型 |

### 1.3 抗性

| 抗性档 | 效果 |
|---|---|
| 弱点 | 承受 +30% |
| 普通 | 0 |
| 抗性 | −25% |
| 免疫 | −100% |

> 敌人自带抗性表（每个 BOSS 单独配），玩家方默认无抗性，靠 MOD 与技能获得。

## 2. 卡牌基础数值

### 2.1 主公式

```
基础值 = 品质基础 × 等级系数 × 职业系数 × (1 + 命座加成) × 随机浮动 × MOD 乘区
```

| 乘区 | 公式 | 说明 |
|---|---|---|
| 等级系数 | 1 + 0.06 × (等级 − 1) | lv80 = 5.74× |
| 职业系数 | 见 §5.1 | 0.90 – 1.10 |
| 命座加成 | +3% / 级 | 本体卡 8 级，其他 6 级 |
| 随机浮动 | 0.97 – 1.03 | 见 §2.4 |
| **MOD 乘区** | 见 §2.5 | 仅 PVE |
| ~~赛季乘区~~ | — | **取消**。签名卡改用「当季奇效 + 上季 +5%」，见 §3 |

**品质基础（C = 400 基准，压缩比固定）**

| 稀有度 | 基础值 | 相对 C |
|---|---|---|
| C | 400 | 1.00× |
| UC | 480 | 1.20× |
| R | 600 | 1.50× |
| E | 740 | 1.85× |
| L | 960 | 2.40× |
| Radiant | 1,160 | 2.90× |
| Prismatic | 1,400 | 3.50× |

> 数值整体比上一版 **×10**。100 ATK 打出去的伤害是两位数，看着难受；要让后期"五位数六位数乱飞"，就得把基数抬起来。
> 压缩比不变（3.5× 上限锁死），**通胀不允许从稀有度里来**。
> 中后期的膨胀由「等级 + 命座 + MOD」承担（见 §3）。

### 2.2 四维

每张卡有 **HP / ATK / DEF / INT** 四维，属性预算恒为 **4.00**。

| 维 | 含义 | 在战斗里怎么用 |
|---|---|---|
| **HP** | 生命 | 队伍血条与单卡血条的基数（§7.1） |
| **ATK** | 物理攻击力 | 物理普攻、物理技能的伤害来源（§6.4） |
| **DEF** | 物理防御 | 吃物理伤害时的减伤基数（§6.4） |
| **INT** | **魔法攻击力（兼魔法防御）** | 魔法技能的伤害来源；同时是吃魔法伤害时的减伤基数 |

> **INT 不是"智力"**，它只有两个用途：作为魔法输出的攻击值，以及作为魔法承伤的防御值。
> MP 是**独立于四维的资源**，只属于法系技能，不参与 4.00 预算（§2.6）。
> 所以法师的 INT 高，意味着它打魔法疼、挨魔法也相对不那么疼 —— 但它血薄，挨物理照样会死。
> 四维之间没有等级、没有成长曲线，全部由 `基础值 × 权重`（§2.1）一次算出。

```
HP  = 基础值 × HP 权重
ATK = 基础值 × ATK 权重
DEF = 基础值 × DEF 权重
INT = 基础值 × INT 权重
```

**四个维度各管什么**

| 维 | 定义 | 参与哪一步计算 |
|---|---|---|
| **HP** | 血条基数（队伍血条 + 单卡血条） | §7.1 |
| **ATK** | **物理攻击力** | 物理技能的「攻击」项（§6.4） |
| **DEF** | **物理减伤基数** | 减伤公式里的「防御」项（§6.4） |
| **INT** | **魔法攻击力，同时兼作魔法减伤基数** | 魔法技能的「攻击」项 / 魔法伤害的「防御」项（§6.4） |

> **INT 不是"智力"，也不是蓝量。** AP 是行动成本，MP 是法系资源（§2.6），三个概念互不替代。
> INT 只是一个名字：它同时是魔法输出的分子、和被魔法打时的分母 —— 法师打人疼、挨打也疼，
> 因为同一项数值两头都在用。这就是为什么法师的 INT 权重高、但要靠坦克挡在前面。

> 权重见 §5.2。四维合计恒为 4.00，子职业之间只做重分配，不做增强。

### 2.3 其他派生值

| 派生值 | 公式 |
|---|---|
| 韧性 | 基础值 × 韧性系数（坦克 1.40 / 战士 1.20 / 法师 0.80 / 辅助 0.90） |
| 迅捷 | **标签，不是数值**（游侠 / 刺客 / 破法者） |
| 命中率 | 基础 95% + 迅捷 +5%（见 §6.4）+ MOD / 技能加成 |
| 暴击率 | 5% + MOD / 技能加成 |
| 暴击伤害 | 150% |

> **速度已降级为标签「迅捷」，不再是一个需要计算的数值。** 它只声明"这卡快"，
> 换来两条固定收益：命中 +5%、被命中 −5%，并且**只有带迅捷标签的卡才能抢攻**（§10.2）。
> 砍掉的理由：数值化的速度原本只剩下"抢攻顺序"一个用途，而抢攻本来就只属于游侠 / 刺客，
> 比大小毫无意义 —— 与其留一个永远算不准的旋钮，不如换成一个直接生效的标签。

### 2.4 随机浮动与补全

| 项 | 数值 |
|---|---|
| 范围 | 97% – 103%（±3%） |
| 目的 | 防止玩家用一张表逆向全部公式 |
| 补全 | 消耗碎片把该卡洗到 103%，**一次性** |

### 2.5 MOD 乘区

> MOD 全量规则在 `经济与养成系统 v0.2.md` §7.3 标注为待定。
> 本文档只约定一件事：**MOD 加成为独立乘区，且只在 PVE 生效**。

```
MOD 乘区 = 1 + (Σ 主词条 + Σ 副词条) / 100
```

**不设硬性天花板。** 按二游刷圣遗物的逻辑，就是会有人去刷"典中典双爆"，让他刷。

| 玩家能刷到的 | 结果 |
|---|---|
| 3 个 6 星双爆 MOD | 暴击率 100%，暴伤 150% |
| 那又怎样 | 伤害仍然要过 §6.4 的公式，还要吃克制、减伤、防御档位 |

> 暴击率 100% 不是问题，它只是把"随机"换成了"确定"，期望值并不会因此翻倍 —— 真正的伤害天花板还是被减伤和防御档位卡住。
> **硬顶会让人"刷到头就没事干"，不设顶才有长期刷的理由。** 代价是后期数值上限不可控，所以要用敌人的减伤档位、免疫、特殊关卡机制来对冲，而不是用玩家侧的封顶。

### 2.6 MP（法系专属资源）

**MP 不是第五维。** 它不参与 4.00 预算，只按品阶给一个定值 —— 所以 14 职业的权重表一个字都不用改。

| 品阶 | C | UC | R | E | L | Radiant | Prismatic |
|---|---|---|---|---|---|---|---|
| **MP 上限** | 10 | 12 | 15 | 18 | 22 | 26 | 30 |
| **每回合回复** | 2 | 2 | 3 | 3 | 4 | 4 | 5 |

| 项 | 规则 |
|---|---|
| 归属 | 只有**法系技能**消耗 MP（咒术师 / 生术师 / 缚术师 / 召唤师 / 圣骑士的神圣系） |
| 物理职业 | MP 恒为 0，UI 不显示这条件 |
| 开局 | 每**章**开始 MP = 上限的 **50%** |
| 回复 | 回合结束时固定回复；**被沉默的回合不回复** |
| 跨战斗 | **章内连续战斗不清空**，MP 带入下一场（与 AP 累积、残血一致，§9.1）；**章节结束才重置** |
| 补蓝 | 因此"回蓝 / 药剂 / 补蓝支援"是有价值的技能位：单场用不上，长战役里决定你能开几次大招 |
| 成长 | **不随等级成长**，只随品阶 —— 升级涨的是 HP / ATK / DEF / INT |
| 与 AP 的关系 | **两者都要付**：AP 是行动成本，MP 是法术次数。因此法系技能的 AP 定价应比同威力的物理技能**低 1–2** |

> 为什么不做成第五维：四维一动，14 职业权重表和品质压缩比要全部重算，牵扯太深。
> MP 是**资源**不是**属性** —— 它回答"这场战斗能放几次法术"，AP 回答"这回合能做几件事"。
> 两者正交，才有"魔法队该堆什么"的 build 空间；如果 MP 只用来加倍扣 AP，那它就是纯粹的负担。

## 3. 签名卡与赛季

### 3.1 不做赛季乘区

签名卡的数值**不随时间自动上涨**。它的强度只有三条来源：

| 来源 | 规则 |
|---|---|
| 基础档位 | 签名卡分 **SSR / SR / R** 三档（见下表），各自对标 Prismatic / Radiant / Legendary |
| 当季奇效 | **只在它所属的那个赛季**生效的专属机制（不是数字），见 §3.2 |
| 上季加成 | 只在**紧接着的下一个赛季**给 **+5%**，再往后归 1.00 |

**签名卡三档**

| 档 | 基础值 | 对标 | 当季奇效数量 |
|---|---|---|---|
| **SSR** | **1,400** | Prismatic | **2 条** |
| **SR** | **1,160** | Radiant | **1 条** |
| **R** | **960** | Legendary | **0 条**（纯数值） |

> 三档与常驻卡的最高三档对齐，所以签名卡的强度**不超过同品质的常驻卡上限** ——
> 它的稀缺性来自"这个赛季只有 10–20 张"，而不是"数值更高"。
> R 档是签名池的保底下限：抽不到 SSR/SR 时，至少拿到的是一张同 L 档的卡，不会掉到 E 以下。

> 就这么多。没有每季 +8% 的滚雪球，所以也不会出现"上一季的卡直接报废"。
> 老签名卡不会变弱，只是**不再有奇效**。收藏意义上它首先是好看，数值上它是一条"这个赛季我参与了"的凭证。

### 3.2 当季奇效

签名卡的强度不放在数字里，放在**规则**里。每张签名卡的奇效**只在当季生效**，季末自动退场。

| 类型 | 例子 |
|---|---|
| 无视减伤 | 当季内，该卡攻击无视目标的减伤与防御档位 |
| 额外段数 | 当季内，该卡所有技能段数 +1 |
| 触发改写 | 当季内，该卡的 Boost / 必杀触发率翻倍 |
| 费用改写 | 当季内，该卡的 AP 费 −1（最低 0） |
| 状态改写 | 当季内，该卡施加的异常状态无法被净化 |

> 奇效就是"这个赛季的卡在这个赛季有奇效"的字面实现。
> 它让签名卡在当季无可替代，但季末自动退场 —— **不靠数值碾压，靠规则碾压**。
> 这也保证下个赛季的签名卡不会比这个赛季的强，只会"更适合那个赛季"。

### 3.3 常驻卡靠什么成长

| 来源 | 上限 |
|---|---|
| 等级 1–80 | 5.74× |
| 命座 6 / 8 级 | +18% / +24% |
| MOD 3 槽 × 6 星 | **无硬顶**（§2.5） |
| 赛季加成 | **无** |

> 常驻卡的上限由**你自己的刷取**决定，不由日历决定。
> 想变强，只能抽更高稀有度、把等级命座堆满、刷更好的 MOD。

### 3.4 PVE / PVP 完全分离

| 项 | 规则 |
|---|---|
| PVE 允许膨胀 | 是，从等级 / 命座 / MOD 来 |
| PVP | 完全分离。PVP 只读卡片**所有权**，不读等级、命座、MOD |
| 不设硬顶 | 低数值可以靠 build 爆杀 BOSS |

> **本文档所有数值与战斗规则只写给 PVE。**
> §6.4 的公式反过来很适合 PVP，以及"BOSS 打玩家"的场景 —— 因为玩家血薄，同样的减伤公式在那边才显得合理。

兰斯10 的核心是"用构筑拆掉数值墙"。既然存在"低数值爆杀"的解，膨胀就只是**降低容错**，不是**关门**。

| 有解 | 无解 |
|---|---|
| 你会打得轻松一点 | 你被挡在门外 |

所以真正要盯的不是"数值够不够"，而是**每关是否至少存在 2 套低数值通关方案**（见 §14 调参）。

## 4. 天赋与技能

### 4.1 数量与结构

| 卡型 | 槽位 | 可选配置 |
|---|---|---|
| C / UC / R / E | 2 | **1 主动 + 1 被动**（固定） |
| **L（Legendary）** | 2 | **2/0**、**1/1**、**0/2** |
| **Radiant / Prismatic / 本体卡** | 3 | 基础 2 槽按 L 的三种配置；第 3 槽解锁「**解锁主动**」或「**解锁被动**」，两者只能存在一种 |

> 「解锁主动」和「解锁被动」**不能同时存在**。所以 R / P / 本体卡最终只会出现四种配置：**3/0、2/1、1/2、0/3**。
> 也就是说，它们比 L 多出来的只是**一个**槽，而且这个槽往哪边加，取决于你选的是哪一种解锁。

| 规则 | 说明 |
|---|---|
| 第 3 技能槽 | Radiant **4 命** / Prismatic **3 命** 解锁；本体卡随本体卡规则 |
| 技能等级 | 1–5，消耗品质碎片 + 金币 |
| 天赋条数 | 2–3 条（品质越高越多） |
| 本体卡 | 职业与天赋可自定义，赛季内可改 1 次 |

### 4.2 洗点（5 次便宜 + 第 6 次自选）

**规则：随机洗点每次都一样便宜（固定 1× 基础），最多连洗 5 次；第 6 次直接自选，价格 = 前 5 次之和。自选后再随机 5 次，如此循环。**

| 次数 | 形式 | 碎片 | 金币 |
|---|---|---|---|
| 1 – 5 | 随机 | 各 **1× 基础**（5 次合计 5×） | 各 1× 基础（合计 5×） |
| **6** | **自选** | **5× 基础**（= 前 5 次加起来） | **5× 基础** |
| 7 – 11 | 随机 | 各 1× 基础 | 各 1× 基础 |
| 12 | 自选 | 5× 基础 | 5× 基础 |

**基础值表**

| 稀有度 | 基础碎片 | 基础金币 | 5 次随机合计 | 第 6 次自选 |
|---|---|---|---|---|
| C | 12 | 36 | 60 / 180 | 60 / 180 |
| UC | 24 | 72 | 120 / 360 | 120 / 360 |
| R | 60 | 180 | 300 / 900 | 300 / 900 |
| E | 150 | 450 | 750 / 2,250 | 750 / 2,250 |
| L | 360 | 1,080 | 1,800 / 5,400 | 1,800 / 5,400 |
| Radiant | **450** | **1,350** | 2,250 / 6,750 | 2,250 / 6,750 |
| Prismatic | **1,200** | **3,600** | 6,000 / 18,000 | 6,000 / 18,000 |

> 随机洗点**不递增**。递增会让"第 4、5 次"贵到没人愿意赌，实际上等于把随机洗点砍成 3 次。
> 自选价 = 5 次随机的总和，也就是**你把抽 5 次的运气一次性用钱买断**。这个价才让人认真权衡"再赌一次值不值"。
> 基础值取 **分解值的 3 倍**（C 12 / L 360），比上一版的递增表整体低一档，确保前 5 次真的"很便宜"。
> **Radiant 与 Prismatic 在这条基础上再砍半** —— 高档卡的技能池更窄、洗到想要的更容易，凭什么更贵？

### 4.3 为什么不做无限随机

无限随机 = 有钱就能刷到想要的 = 天赋变成氪金/时间比拼。
5+1 的循环把"运气"封顶在 5 次，第 6 次回到"钱换确定"。

## 5. 职业系统

### 5.1 四大类

| 大类 | 职业系数 | 定位 |
|---|---|---|
| 坦克 | 0.90 | 吃 down、站桩、保人 |
| 战士 | 1.10 | 输出主力、连击、破甲 |
| 法师 | 1.05 | 法术输出、治疗、控制、召唤 |
| 辅助 | 0.95 | AP、增益、打断、救场 |

> 「术士」改名「法师」。更直白，也让 INT 这个属性名对得上。

### 5.3 关于"坦克只有两档是不是太少"

**不加。**

**「反击坦」不做成第 15 个职业，改做机制。**

| 一方 | 形态 |
|---|---|
| 我方 | 状态 **荆棘**（§11.1），挂在卡上 2 回合 |
| 敌方 | 侧面支援 **荆棘栅栏**（§8.1），清支援即可拆 |

> 反伤是**挂件**，不是职业身份。坦克仍然只有肉坦 / 战坦两档 —— 想要反伤，带一张上了荆棘的卡就行，
> 不需要为此多开一个子职业。

**舞者的两种形态**

| 形态 | 机制 | 取舍 |
|---|---|---|
| **被动挂件** | 该回合 AP 恢复 **2 → 3**，不占行动（= §6.2 天赋「舞者增幅」） | 稳定，但只是一张"摆着不亏"的卡 |
| **主动爆发** | 花 2 AP（占行动），全队本回合 AP **+3**，每场 2 次 | 净赚 1，但把 AP 集中在关键回合，是 6–7 费大技能的启动开关 |

> 两种形态同时存在，玩家按卡池选。**第二条 AP 窄口**就在天赋池里（§6.2）：
> 依附舞者的「舞者增幅」，以及完全独立的「无偿」（0 AP 换 1 AP）—— 量小、无条件，绝不替代舞者。

## 6. 基本战斗流程

### 6.1 回合结构

```
我方 Round
  ├─ 回合开始：结算 DOT / 恢复 / AP
  ├─ 侧面支援行动（主队之外，先结算）
  ├─ 抢攻判定（无需 AP）
  ├─ 主队行动（7 张卡，消耗 AP）
  └─ 回合结束：Combo 清零
敌方 Round
  └─ 按敌方模板行动
```

> 与兰斯10 一致：敌我交替，我方先手。敌方通常只有 **1 个单位**（一个军团算作一个敌人），但支持多敌人。
> **顺序是 侧面支援 → 抢攻 → 主队**：支援先结算完，才轮到抢攻判定，最后才是主队正式消费 AP。
> 这样"支援铺 Combo、抢攻补 Combo、主队吃 Combo"是一条完整的链，中间不插队。

### 6.2 AP（行动点）

| 项 | 数值 |
|---|---|
| 每回合基础恢复 | **+2** |
| 上限 | **7**（初始上限，不是开局就给 7 点） |
| **开局 AP** | **2** |
| 回归 | **未用掉的 AP 累积到下一回合**，上限 7 |

> 开局就给 2，是因为这套系统里存在 **1 费甚至 0 费**的技能。0 费技能和普攻一样，
> 意味着可以一整轮"砍了一遍发现没掉费"——这不是 bug，是"0 刀队"的合法打法（见 §6.6）。
> 只要开局不是 0，第一回合就能动；只要开局不是 3，你就得在第 1 回合做取舍。

> **AP 必须能继承**，否则 6–7 费的大技能永远放不出来 —— 每回合只进 2 点、当回合打完就归零，
> 大技能等于不存在。代价是：囤 AP 就成了战术，你要在"这回合开大招"和"这回合不开罐就死"之间选。

**AP 天赋池 / 部队加成（只有 Radiant 及以上 + 本体卡能抽到）**

| 天赋 | 效果 |
|---|---|
| **部队加成（二选一）** | **扩容**：AP 上限 7 → 10；**或** **偶数回合**：该回合额外 +3 AP |
| 舞者增幅 | 队伍有舞者时，该回合 AP 恢复 **2 → 3** |
| 空转 | 回合开始时若 AP = 0，额外 +1 |

**AP 卡牌效果（写在卡上，不是天赋）**

| 效果 | 机制 |
|---|---|
| **无偿** | 0 AP 换 1 AP；**前 3 回合锁定**，**第 4 回合起**才能用。用过后**下一回合变成 1 AP 换 1 AP**（疲惫），再下一回合恢复 0 换 1 |
| **霞艾拉** | **3 AP 补满至当前上限**：上限 7 就回 7，上限 10 就回 10；不占行动，每回合限 1 次 |
| 0 → 3 AP | **暂不启用**：需要"到恢复点之前只许用一次"的赛季式主线结构才成立 |

> **霞艾拉是终局卡**：它本身不生产 AP，它把"不可能的 BOSS 战"变成可能。
> 双舞者叠起来也不过 4 AP/回合，代价是两个位置被吃掉 —— 位置本身就是成本，不需要额外惩罚。

> **大技能（4–7 费）贵在"铺垫"**：不铺垫没有伤害，铺垫了就没有防御，等于多挨打。
> 所以它天然是"高风险窗口"，不是"每回合的常规选项"。

### 6.3 行动规则

| 规则 | 说明 |
|---|---|
| 每张卡每回合只能行动 **1 次** | 行动完毕即结束 |
| 被动不计入行动 | 被动常驻生效 |
| 行动消耗 AP | 技能有各自的 AP 费，**可以 0 费** |
| 侧面支援 | 主队之外，每回合自动行动 1 次，**先于抢攻与主队**，不消耗 AP |
| 抢攻 | 支援结算后免费攻击，不占行动次数 |
| **防御** | 独立指令，不占行动次数，见 §6.7 |

### 6.4 伤害公式

```
最终伤害 = 攻击 × 技能倍率 × 触发修正 × Combo 修正 × 克制系数 × (1 − 减伤) × (1 − 防御档位) × 随机(0.95–1.05)

攻击     = 物理 → ATK；魔法 → INT
减伤     = min( 防御 / (防御 + 10,000), 0.70 )
防御     = 物理 → 目标 DEF；魔法 → 目标 INT
防御档位 = 0 / 20% / 40% / 70% / 90%（主动防御，见 §6.7）
```

| 修正 | 来源 |
|---|---|
| 触发修正 | Boost 1.5 / 必杀 3.0 / 连击 ×2 次（见 §10） |
| Combo 修正 | 见 §9 |
| 克制系数 | 见 §1.2 |
| 减伤 | 由 DEF / INT 决定，封顶 70% |
| 防御档位 | 独立乘算，最高 90% |

**命中判定（在减伤之前结算）**

| 项 | 规则 |
|---|---|
| 基础命中 | 95%；**迅捷标签 +5%**；再叠状态修正（混乱 −20% 等） |
| 未命中 | 该次 **0 伤害**，且 **Combo 减半**（向下取整） |
| 多段 | 逐段判定；某一段未命中，只对**该段之前已累积的 Combo** 减半，余下段数继续正常累计 |

> **未命中是"打对折"，不是"清零"。** 清零的方差太大：95% 命中率下打 10 次，至少 miss 一次的概率约 40%，
> 那等于 40% 的回合你的整轮铺陈直接报废 —— 这不是"高闪避关的第二把锁"，是抽卡。
> 减半保留了惩罚的方向性（越长的 Combo 损失越大），但不会让一次 miss 否掉整轮决策。
> 它仍然是高闪避关的第二把锁：你可以靠堆连击打穿减伤，但一次 miss 就会让收益腰斩。

**数字量感（L 卡满级，单段普攻）**

| 步骤 | 计算 | 结果 |
|---|---|---|
| 攻击 | 960 × 5.74 × 1.10 | ≈ 6,060 |
| × 倍率 / Combo / 克制 | 1.0 / 2.8 / 1.25 | ≈ 21,200 |
| × (1 − 减伤 44%) | | ≈ 11,900 |
| 再打 90% 防御档位 | | ≈ 1,190（**"不开罐就打不动"**） |

> 后期是"五位数六位数乱飞"的，前提是**别去碰 90% 防御的关**。数字大不大，取决于关卡给你开不开罐。

### 6.5 技能费用模型

技能除了"多少 AP"，还带一个**费用标签**。同一次远征内可以混用，但每个技能只属于一种标签。

| 类型 | 费用 | 规则 |
|---|---|---|
| **常态** | 固定 | 写多少就是多少，每回合都能用 |
| **疲惫** | 基础 + 1 | 该技能**上一回合刚用过** → 本回合 +1 AP。只 +1，不叠层、不累积 |
| **AP 累积（远征）** | 基础 + n | 在**整个赛季远征**内每用过 1 次，此后永久 +1 AP。换人不清零，赛季结束重置 |
| **单次** | 基础 | **整场战斗只能用 1 次**（0 费的单次技能同样限 1 次） |
| **MP 型** | AP + MP | 法系技能：AP 照付，另扣 MP（§2.6）。定价时 AP 应比同威力的物理技能低 1–2 |

**疲惫的判定（只持续 1 回合）**

```
情况 A：连用
  Round 1  用【1 AP 技能】→ 花 1
  Round 2  再用           → 花 2（疲惫）
  Round 3  还用           → 花 2（Round 2 也用了，疲惫继续）
  Round 4  还用           → 花 2（一直连用就一直疲惫）

情况 B：停一回合
  Round 1  用 → 花 1
  Round 2  不用
  Round 3  再用 → 花 1（上一回合没用过，疲惫已过）

情况 C：Round 1 用，Round 2 用，Round 3 不用，Round 4 再用
  Round 3 不用 → Round 4 花 1（Round 3 是空的，疲惫不延续）
```

> **疲惫只问一句"上一回合有没有用过这个技能"。** 用过就 +1，没用过就恢复原价。
> 它不会累积成 +2、+3，也不会因为你换了别的技能就立刻消失 —— 只看上一回合。

**AP 累积（远征）的判定**

```
第 1 次用 → 花 1
第 2 次用 → 花 2
第 5 次用 → 花 5
第 n 次用 → 花 n（封顶 = AP 上限 7，超过就再也用不出来）
```

> 这是**赛季维度**的价签。远征早期的 1 费大招极其划算，中期开始肉疼，后期直接封死。
> 它天然适配"兰斯10 式的有限回合远征"：越往后越要省，而不是越往后越爽。

**四类标签的设计意图**

| 标签 | 用来做什么 | 反面 |
|---|---|---|
| 常态 | 稳定输出、队伍的地板 | 没有 |
| 疲惫 | 高伤技能的门槛 | 逼玩家配两个同类技能轮流用 |
| AP 累积 | 一次性爆发的定价 | 前期白给，后期变废 |
| 单次 | 开场的"这一刀" | 用早了就没了 |

**允许"卖血换输出"的技能**

消耗自身 HP 或韧性换取伤害 / AP 是合法的设计方向，典型归属狂战士。规则只有三条：

- 扣的是**单卡 HP**，所以会同步拉低队伍血条（§7.1），不是免费的资源
- **不能把自己扣到 0**：最低保留 1 HP；想扣到 0 就是自杀，直接走 down（§7.3）
- 扣韧性不触发眩晕（§7.2），但会让这张卡更容易被下一次破韧打穿

> 这类技能的价值在于"用可控的损失换不可控的收益"——它让"血线"变成一个可以主动管理的资源，
> 而不是只能被动挨打。

### 6.6 多段技能（平刀队 / 0 刀队）

**技能可以是「N 费打 X 次、每次造成 0.X 倍伤害」。** 这条一开，"平刀队"才有引擎。

| 项 | 规则 |
|---|---|
| 结算 | 每一段**独立结算**：独立随机浮动、独立暴击、独立克制与减伤 |
| Combo | 每一段各自 **+1 Combo**，后段吃前面叠起来的加成（见 §9） |
| 触发 | Boost / 必杀 / 连击按**整次行动**判定一次，命中则该行动所有段统一享受 |
| 减伤 | 减伤是**百分比**不是固定值，所以多段不吃亏 —— 这是多段技能能成立的前提 |
| 0 费 | 原则上**单段**，倍率 ≤ 0.6。它的价值在铺 Combo，不在伤害 |

**为什么多段能赢**

```
平刀 2 段 × 0.55，从 Combo 0 起手
  第 1 段：Combo 1 → +0%   → 0.55
  第 2 段：Combo 2 → +0%   → 0.55
  合计 1.10，并且把 Combo 推到 2
```

同样是 1 费，单段技能只能把 Combo 推到 1。**多段换来的不是伤害，是 Combo 速度。**

**起手位置决定收益**

| 技能 | 费 | 段数 | 单段倍率 | 从 Combo 0 起手 | 从 Combo 5 起手 |
|---|---|---|---|---|---|
| 普攻 | 0 | 1 | 1.00 | 1.00 | 1.00 |
| 平刀 | 1 | 2 | 0.55 | **1.10** | **2.09** |
| 三连 | 2 | 3 | 0.40 | **1.20** | **2.44** |
| 乱舞 | 3 | 4 | 0.32 | **1.36** | **2.76** |

> "从 Combo 5 起手"= 侧面支援 + 抢攻已经先铺了 5 下，主队再动。
> 这就是为什么侧面支援必须**排在主队之前**（§6.1）：它就是平刀队的起手铺陈。
> 同费用的单段技能总倍率要**略高于**多段（约 +5–10%），用伤害换 Combo 速度，两边才等价。

### 6.7 防御指令

兰斯10 里防御是**单独一个按钮**。这里也一样：不占行动次数，只花 AP，是"这回合认怂"的保险。

| 档位 | 累计 AP | 坦克大类（肉坦 / 战坦 / 圣骑士） | 非坦克 |
|---|---|---|---|
| I | 1 AP | −20% | −20% |
| II | 2 AP | −40% | −30% |
| III | 3 AP | −70% | −50% |
| IV | 4 AP | −90% | **锁死**（不可选） |

| 项 | 规则 |
|---|---|
| 生效范围 | **全部伤害**，不分物理 / 法术、近战 / 远程 |
| 持续 | **仅本回合**，回合结束清空，下一回合要重新按 |
| 升档 | 同一回合内可连续升级 I → II → III → IV，每升一级再花 1 AP |
| **不可反悔** | 一旦升档，本回合**不能降档、不能退回 AP** |
| 与减伤 | **独立乘算**：`(1 − 减伤) × (1 − 防御档位)` |
| 与支援 | 侧面支援里也可以有「重装甲 I–III」的单位，提供同档效果（§8） |

> **IV 档是坦克的职业特权，不是人人都能开罐。** 90% 那一档是给**特殊关卡**设计的：有的关就是"不开罐打不动"，
> 你必须带坦克、花 4 AP 叠到 IV，再用剩下的 AP 输出 —— 没带坦克，就永远只能停在 −50%（而且要多花 AP）。
> 这是 AP 的第三个去处 —— 一个回合的 AP 不全都是用来打人的。

**特殊关卡的两条机制**

| 机制 | 规则 |
|---|---|
| **装甲** | 该关敌人常驻 X% 防御档位（I–IV），必须用"破甲 / 开罐"手段才能临时削掉 |
| **伤害门槛** | 单次伤害低于 Y 时**只结算固定 100 点**，需要"打够 N 次"而不是堆一个大数字 |

> 这两条保证后期"数字不是唯一解"：它们让纯堆暴击的 build 有对手，也让多段 / 平刀队在特定关卡变成正解。

### 6.8 嘲讽与仇恨（坦克大类通用）

| 项 | 规则 |
|---|---|
| 归属 | **坦克大类全部可嘲讽**：肉坦 / 战坦 / 圣骑士 |
| 代价 | 1 AP，不占行动次数 |
| 效果 | 本回合敌方**单体攻击**强制以嘲讽者为目标；**群体攻击不受影响** |
| 唯一性 | 同一时间只能有 1 个嘲讽生效 |
| **down 优先** | 坦克仇恨最高：**down 判定优先落在坦克**；坦克已被 down、或嘲讽已失效，才轮到其他卡 |
| 失效 | 嘲讽者被 down → 嘲讽立即解除 |

> 坦克的看家本事不是"血厚"，是"**替别人挨 down**"。嘲讽不是一个减伤按钮，
> 它是在替整队挡掉最贵的那一条判负 —— 这也是坦克不出场的关卡没法打的根本原因。

### 6.9 蓄力

| 项 | 规则 |
|---|---|
| 本质 | 蓄力是**侧面增益效果**，每回合叠 1 层，提升该单位的攻击力 |
| 期间 | **蓄力单位仍在普攻**，不是站着不动 |
| 满槽 | 满层后可释放大招；意图预告会直接标出"可放大招" |
| 打断 | **蓄力可以被打断**（刺客打断、硬控都算） |
| 打断后 | 目标进入**脆弱**（§11.1）：**受到伤害 +30%**，持续 2 回合 |
| 变体 | 部分敌人被打断后进入**狂暴**：ATK +40% / DEF −30%，持续到战斗结束 |

> 蓄力是"你不动手就死、你动手就赌"的经典二选一。
> **打断不是白赚** —— 你换来的是一段脆弱窗口，不是把大招直接取消掉。
> 而狂暴变体是给那些"打断反而更危险"的敌人准备的，让玩家自己判断该不该动手。

## 7. 血条、韧性与 Down

### 7.1 三层血条

| 层 | 定义 |
|---|---|
| 卡片血条 | 每张卡各自的 HP |
| 队伍血条 | **= 所有卡片血条之和** |
| 韧性条 | 每张卡各自的 Poise |

- **队伍血条归零** → 我方败。
- **敌方血条归零** → 我方胜。

### 7.2 韧性归零 = 眩晕

| 项 | 规则 |
|---|---|
| 触发 | 韧性条归零 |
| 效果 | 该卡在**下一个我方 Round** 无法行动 |
| 自然恢复 | 未破防时，每回合恢复 **30%** 韧性（上限为满） |
| 破防后恢复 | 眩晕 1 回合结束后，**直接回满 100%** |
| 治疗 | 不影响韧性恢复 |
| 例外 | 坦克类天赋可缩短为"半回合" |

> 30% 自然恢复，意味着"连续两回合被打"才会真正破防。
> 但一旦破了，就是**罚站 1 回合然后彻底复原** —— 不是半残慢慢爬，而是"这回合废了，下回合满血回来"。
> 这样破防是可预期的战术事件，而不是不可逆的死亡螺旋。

### 7.3 Down（下场）

| 情形 | 处理 |
|---|---|
| 卡片血条归零 | **本场永久 down**，直接下场 |
| 被敌方"down 技能"打中（血未归零） | 倒下，但**不是死亡** |
| 主线 | 无牌可换 → **留在场上**，3 回合后自动清醒 |
| 赛季 / 周本特殊关 | 有后备 → 换人；无后备 → 永久 down |
| 治疗带"抬人"技能 | 可提前救回，继续打 |
| 行动已开始 | **不能再换人** |
| 换上来的人 | 本回合结束前不能行动 |
| 赛季例外 | 若被 down 且后置卡还没行动 → **该回合可直接上场并行动** |

> 主线不做替补席，是因为主线的节奏是"一路向上"，玩家只带 7 张，中途换人会破坏叙事。
> 赛季和周本才给替补，因为那两个模式本来就是"资源分配"。

### 7.4 我方被削弱的全部来源

| # | 来源 | 效果 |
|---|---|---|
| 1 | 韧性条归零 | 眩晕，下回合不能行动 |
| 2 | 卡片 / 队伍血量低于特定比例 | 部分职业**低于 30% 时反而增强**（狂战士、咒术师） |
| 3 | 队伍整体负面状态 | 见 §11 |
| 4 | 卡片被 down | 见 §7.3 |
| 5 | 支援格被占用 / 锁死 | 见 §8 |
| 6 | AP 被削减（恐惧） | 少 1 点 = 少一次行动 |
| 7 | 沉默 | 法师 / 辅助无法使用主动 |
| 8 | 破防 | 防御档位降 1 级；已为 0 时改为削 DEF |

> 第 2 条要写进天赋池：**狂战士与咒术师有"残血增强"天赋**，这让"被压血"对某些 build 是收益而不是惩罚。

## 8. 侧面支援

### 8.1 定义

**侧面支援不属于队伍。** 它是主队（7 张卡）**之外**的独立栏位，敌我双方各最多 7 个，独立于主队的行动轮。

**支援不一定是"部队"。** 它可以是：

| 形态 | 例子 |
|---|---|
| 召唤物 / 援护部队 | 召唤师召出来的东西、别队派来的援护 |
| 魔法阵 / 魔法护盾 | 场地效果、护盾结界 |
| 常驻状态 | 鼓舞、军师、战意、气势 |
| 重装甲 | 给全队套上防御档位 I–III（§6.7）；**IV 档只有坦克本人在场才能开**。战坦是唯一能主动提供它的职业 |
| 荆棘栅栏 | 敌方布下的**反伤支援**：打敌方主队的每一段都要吃固定反伤（§11.1 荆棘） |

**两类支援，行为完全不同：**

| 类别 | 行为 |
|---|---|
| **攻击型** | 每回合按**发动率**自动攻击 1 次（伤害按 50%，命中照常 +1 Combo） |
| **支援型** | **不攻击**，常驻提供属性加成 / 减伤 / 状态，不判定发动率 |

| 项 | 数值 |
|---|---|
| 双方上限 | **7 个** |
| 我方防御 | **占用 1 格**（只允许 1 张防御卡） |
| 行动顺序 | **在主队之前**，且**先于抢攻** |
| 位置 | 敌方支援在画面**左侧**竖排，我方在**右侧**竖排，对称；未解锁格显示锁 |
| 攻击型伤害 | 按 50% 计 |
| 攻击型发动率 | **60%**（可按技能 / 天赋抬升） |
| 支援型 | 常驻生效，不发动 |
| AP | 自动行动不消耗 AP；主动支援技能消耗 1 AP |
| 锁定 | 被锁定的支援不会消失，除非对方有**解锁技能** |

> **"排在主队之前"是这套系统的全部价值。** 支援先打，把 Combo 铺上去，主队的技能再吃高 Combo 加成。
> 支援不是"多打几下"，而是"把你的最后一刀抬高"。如果让支援跟在主队后面，它就只剩伤害，Combo 完全吃不到。
> **把防御算进支援格，是可以的，但只占 1 格。**
> 全占 7 格会变成"大家都去点满防御"，战斗失去节奏；占 1 格则是"你想挡刀就得少带一个召唤"，刚好治贪心鬼。
> 这也让"圣骑士保支援"有了明确对手盘：对面有削支援的技能时，你才需要他。

### 8.2 支援的来源

| 来源 | 说明 |
|---|---|
| 召唤类技能 | 召唤师、部分战士 |
| 职业被动 | 生术师、圣骑士 |
| 增益技能 | 吟游诗人、军师类状态 → 支援型 |
| 防御位 | 我方固定 1 格，或重装甲 I–IV |
| 敌人 | 敌方也能加支援（§12 第 7 条） |

## 9. Combo

### 9.1 规则

| 项 | 规则 |
|---|---|
| 累积 | **每次命中 +1**（多段技能的每一段各算 1 次；侧面支援、抢攻也计入） |
| 清零 | 我方回合结束清零；**攻击未命中则 Combo 减半**（§6.4） |
| 作用 | 第 N 次命中按 **Combo N** 的加成结算，不追溯前面的段 |
| 上限 | **效果封顶在 10 Combo**，但**显示没有上限**（100 Combo 也照显示，只是加成不再涨） |

> 显示不封顶是为了让"我就想看看能连多少"变成一种玩法；效果封顶是为了让数值不失控。两件事分开做。

> 多段技能是 Combo 的加速器：一个 4 段技能一次行动就能把 Combo 从 0 推到 4，
> 而单段技能只能推到 1。这就是"平刀队"和"大招队"的分野 —— 前者靠段数滚起来，后者靠起手位置吃满。

### 9.2 曲线

| Combo | 额外伤害 |
|---|---|
| 1 – 2 | 0% |
| 3 | **12%** |
| 4 | 26% |
| 5 | 51% |
| 6 | 77% |
| 7 | 103% |
| 8 | 129% |
| 9 | 154% |
| 10 | **180%（效果封顶）** |

> 4 → 10 是线性斜坡，每层约 25.7%。第 3 层给 12% 是"象征性"的：
> 前期铺场不该是纯亏，但也不该一上来就滚雪球，12% 刚好够让人感觉"连起来了"。
> 2 以下没有加成是**故意**的：它让"前几下用来铺场"和"最后几下用来收割"变成两种战术选择。

### 9.3 180% 是不是太高

**不算高，但它是这套战斗的地基，不能随便动。**

| 理由 | 说明 |
|---|---|
| 达成条件苛刻 | 10 Combo 需要 10 次命中；7 张卡 + 7 支援 = 14 次行动，还要吃 AP 上限 |
| 只有 Radiant 以上能稳定打满 | 普通卡没有 AP 扩容与回复天赋，实际最高约 6–7 Combo |
| 它是"最后一刀"的奖励 | 前 2 刀 0 加成，第 3 刀才象征性给 12%，铺场本身仍然接近白给 |

**如果上线后发现滚雪球太猛，只调这两处：**

1. 把封顶从 180% 降到 **140–150%**
2. 把斜坡改成前段更平（3–6 只有 0/10/20/35%）

> 不要动"2 以下无加成"和"回合结束清零"。这两条一改，Combo 就从"战术选择"变成"永动机"。

## 10. 特殊触发

### 10.1 Boost / 必杀 / 连击

| 触发 | 效果 | 初始触发率 |
|---|---|---|
| **Boost** | 伤害 ×**150%** | 5% |
| **必杀** | 伤害 ×**300%** | 2% |
| **连击** | 该次行动执行 **2 次** | 3% |

**获得与消耗**

| 环节 | 规则 |
|---|---|
| 获得 | 每回合开始时，每张卡各自掷一次，判定本回合是否"蓄到"触发 |
| 消耗 | 该卡**主动放出技能**时消耗，加成生效 |
| 未消耗 | 该卡本回合没主动放技能 → 加成**作废**，不带入下回合 |
| 不叠 | 同一张卡同一回合最多获得 **1 种**，Boost / 必杀 / 连击不叠 |
| 来源 | 初始值很低，靠 MOD、天赋、专拐抬升 |

> **这三个是"卡身上的状态"，不是"行动上的运气"。**
> 蓄到了却没放技能，就是白蓄 —— 这逼你"蓄到就必须动"，而不是把大招一直捏在手里等更肥的回合。

### 10.2 抢攻

| 项 | 规则 |
|---|---|
| 归属 | **带「迅捷」标签的卡**（游侠 / 刺客），其他卡没有（§2.3） |
| 时机 | 侧面支援结算之后、主队行动之前 |
| 代价 | **不消耗 AP，不占行动次数** |
| 伤害 | 按 **70%** 计 |
| 初始触发率 | 4% |
| 作用 | 补 Combo、压制敌方速度 |

> 抢攻存在的意义是"先手"。速度快的职业先摸一下，把 Combo 的起手抬高 —— 所以它和侧面支援是同一套逻辑，
> 都是"在主队正式动手之前，把地板垫高"。

> **抢攻只有一种态度：凹。** 不提供"这张卡不要抢攻"的开关 ——
> 它是一整个流派（游侠 / 刺客 build 的立身之本），不是可以随手关掉的小毛病。

### 10.3 "专拐"

某个卡的存在意义就是给另一个卡抬触发率 —— 这是 build 多样性的主要来源之一。
初始 5% / 2% / 3% 是"偶尔见到"的档位，抬到 30–50% 才是"这套队在运转"的档位。

### 10.4 打断（刺客专属）

| 项 | 规则 |
|---|---|
| 归属 | **刺客**。游侠不打断 —— 游侠吃的是"虚弱后收割"（§5.2） |
| 时机 | 敌方意图已公开（§12.2）、行动尚未结算之前 |
| 第一步 | 命中判定：95% + 迅捷 +5%，走 §6.4 的常规命中 |
| 第二步 | 命中后**再 roll 一次"打断哪一个"**：从该敌人本回合的 N 个行动里**随机抽 1 个** |
| 第三步 | 被抽中的那个行动：基础 **50%** 打断成功；精英 40%；BOSS 30%；目标每 1 层韧性抗性再 −10% |
| 失败 | **0 伤害、Combo 减半、AP 照付** |
| 限制 | 每方每回合最多 **1 次**打断尝试 |
| 可打断范围 | **默认全部可打断**，包括 BOSS 的大招；只有标红「无法打断」的例外（约 1/3 的招牌技） |

> **玩家控制不了打断谁。** 这才刺激 —— 兰斯10 的凹点就在这里，
> 用"随机抽一个"代替"玩家指定"，打断才不会退化成"看见高伤就必打断"的精确解。
> 同时它把打断天然限制在"多动作敌人"身上：敌人一回合动 4 次，你赌中的概率就只有 1/4。

## 11. 异常状态

### 11.1 状态表

| 状态 | 作用对象 | 效果 | 持续 |
|---|---|---|---|
| **冻结** | 队伍 | 受冰伤 +20%，**失去迅捷标签**（有概率行动失败 25%） | 2 回合 |
| **触电** | 队伍 | 受雷伤 +30% | 3 回合 |
| **燃烧** | 队伍 | 受火伤 +20%，每回合失去最大生命 3% | 3 回合 |
| **中毒** | 队伍 / 卡片 | 每回合失去**当前生命 2% / 3% / 5%**（按技能档位），**不可叠加** | 4 回合 |
| **恐惧** | 队伍 | 每回合 AP 恢复 **−1** | 3 回合 |
| **魅惑** | 卡片 | 行动时 50% 概率攻击错误目标（含友军） | 1 回合 |
| **流血** | 队伍 / 卡片 | 每回合失去**最大生命 1%**，最多 **5 层**（合计 5%） | 3 回合 |
| **混乱** | 卡片 | 30% 行动失败，命中 −20% | 2 回合 |
| **诅咒** | 队伍 / 卡片 | 结束时一次性扣除当前生命 **15%** | 3 回合 |
| **沉默** | 卡片 | 法师 / 辅助无法使用主动技能 | 2 回合 |
| **破防** | 队伍 | **防御档位降 1 级**；已经是 0 档时，改为直接削 DEF | 3 回合 |
| **眩晕** | 卡片 | 该卡在指定回合无法使用主动 | 1 回合 |
| **治疗阻断** | 队伍 / 卡片 | 受到的治疗量 −50% | 2 回合 |
| **衰弱** | 队伍 / 卡片 | ATK / INT −20% | 3 回合 |
| **迟缓** | 卡片 | **失去迅捷标签**，抢攻失效 | 2 回合 |
| **支援排除** | 支援 | 目标支援栏的 1 个支援无法行动 | 2 回合 |
| **荆棘** | 卡片 | 每受到**一段**攻击，反伤一次固定值（算魔法伤害，见下方细则） | 2 回合 |
| **警觉** | 敌人 | **免疫硬控**（精英/BOSS 被硬控后自动获得，见下方细则） | 3 回合 |
| **脆弱** | 敌人 | **受到伤害 +30%**（蓄力被打断后，§6.9） | 2 回合 |
| **狂暴** | 敌人 | ATK +40%、DEF −30%，持续到战斗结束（部分敌人被打断蓄力后） | 永久 |

**破防的细则**

```
破防 1 层：IV → III → II → I → 0（一级一级往下掉）
已经是 0 档：改为削 DEF
  第 1 层  −20%
  第 2 层  −40%
  第 3 层  −70%
  第 4 层  −90%
```

> 破防打的是"**防御档位**"，不是 DEF 本身。所以在敌人开罐（IV 档）时，破防是最有效的解法；
> 而敌人本来就没开防御时，破防才退化成"削 DEF"。

**荆棘的细则**

```
结算   每受一段攻击立即反伤一次，不合并成一次
数值   固定值 = 附着卡 INT × 系数（写进技能），不随受到的伤害大小浮动
属性   反伤算魔法伤害，按攻击方 INT 减伤
上限   每行动最多反伤 3 段（防 4 段队被一次团灭）
死亡   攻击方被反伤打死 → 该行动剩余段数直接取消
不参与 不触发 Combo / 暴击 / Boost / 必杀 / 吸血
```

> **为什么必须是"逐段固定值"**：百分比反伤（按受到伤害的 X% 反弹）对多段是中立的 ——
> 反弹总额 = 总伤害 × 百分比，打 1 段和打 4 段一样多。只有每段固定值才能真正惩罚平刀队，
> 这也正是它存在的理由。反过来，法师吃反伤少、物理队吃满，形成"法师克制荆棘"的闭环。

**硬控：眠咒 / 击晕**

两种形态、同一套规则 —— 眠咒偏法术（缚术师），击晕偏物理（战坦）：

| 项 | 规则 |
|---|---|
| 消耗 | 3 AP，且该卡本回合不再有其他行动 |
| 判定 | 非精英 80% / 精英 65% / BOSS 50% |
| 时长 | 作废目标本回合**全部剩余行动** |
| **打醒** | **该目标受到任何命中即立刻解除** —— 控住之后不许打，打了就放出来 |
| 精英 | 每场最多被硬控 **2 次**，之后进入「警觉」（§11.1） |
| 蓄力 | 硬控**可以打断蓄力**，打断后目标进入「脆弱」（§6.9）；没打断就照常放大招 |

> **打醒是这个系统里最漂亮的一处冲突**：硬控和抢攻 / 平刀天生对立 ——
> 你要控住他，整队就得收手；你要输出，就等于替他解控。玩家必须二选一，没有"全都要"。

**硬控 / 软控 / 打断的分层**

| 类型 | 谁有 | 代价 | 效果 |
|---|---|---|---|
| 硬控（眠咒 / 击晕） | 缚术师 / 战坦 | 3 AP + 占整次行动 + 打醒 + 精英限 2 次 | 作废目标本回合全部剩余行动 |
| 软控（魅惑） | 缚术师 | 2 AP，按 INT 判定 | 目标 50% 打错目标，持续 2 回合，**打醒不解除** |
| 打断 | 刺客 | 技能费 | 随机取消 1 个**已预告**行动，50%（§10.4） |

> 三档按"代价换确定性"排序：硬控最贵但最稳，打断最便宜但只能赌。
> 软控夹在中间 —— 便宜、不占整次行动，但只削一半的行动。

**警觉（硬控的免疫窗口）**

```
触发   精英 / BOSS 每次被硬控成功后立即获得
效果   3 回合内免疫一切硬控（软控与打断不受影响）
意义   硬控打不出"永久锁死"；精英限 2 次 + 警觉，用完就得换目标
```

> 警觉是"次数上限"之外的软闸 —— 就算你 AP 富到能连控，中间这 3 回合也得靠平刀顶过去。

**毒与流血为什么这么低**

兰斯后期敌人动辄几百万上千万 HP，纯靠 DOT 磨死就是三周目的轮椅打法。
所以：**毒不叠层**（2% / 3% / 5% 三档），**流血封顶 5 层 = 5%/回合**。
它逼你"平时还是得打伤害"，而不是"挂满毒然后跑路"。

> **DOT 不吃任何修正**：不受 Combo、属性克制、触发、减伤、防御档位影响，只按目标当前 / 最大生命算。
> 这是它"慢但稳"的代价 —— 也正因为如此，它不会被任何增伤手段放大成秒杀。
> 轮椅的解法不是砍数字，而是 §12.3 的星级：DOT 队能过关，但拿不到 ★1 速通。

> 「魅惑」的具体数值是我替你补的：**50% 攻击错误目标**。原因是"完全失去控制"会让玩家觉得不公平，而"打错人"既有风险又好笑，适合这个题材。

## 12. 敌方行动模板

| # | 行动类型 | 效果 |
|---|---|---|
| 1 | 物理攻击（近战 / 远程） | 常规伤害 |
| 2 | 魔法攻击（属性攻击） | 带属性克制 |
| 3 | 增幅自身 | 自 buff、回血 |
| 4 | 上负面状态 | 概率不低（建议 60–80%） |
| 5 | **高额物理攻击（×3 以上）** | 可能附带 down |
| 6 | **高额魔法攻击（×3 以上）** | 可能附带负面 + down |
| 7 | 增加侧面支援 | 往侧边栏添加单位（受 7 格上限约束） |
| 8 | **削减 / 无力化玩家支援** | 一次性消耗 ≥2 个支援 |

> 第 8 条是 §8 锁定机制与圣骑士存在的理由。没有敌人的"拆支援"，支援系统就只是单方面的收益。

### 12.1 敌人配置建议

| 敌人类型 | 每回合行动次数 | 行动权重 |
|---|---|---|
| 小怪（低 T） | 1 | 1 / 2 |
| 小怪（高 T） | **3 – 4** | 1 / 2 / 4 |
| 精英 | **2 – 3** | 1 / 2 / 4 / 5 |
| BOSS | **3 – 4** | 全部 8 类 |

> 兰斯10 的高 T 小怪就是能一回合 4–5 动、顺手上一堆 debuff。这里对标那个强度，不搞"小怪只打一下"的温柔版。
> 高 T 小怪的多动，主要是为了让**防御指令**和**治疗/净化**有存在的意义 —— 一回合只挨一下，谁都不用防。

> **敌方必须配"破韧"手段。** 我方韧性条（§7.2）不是摆设：精英与 BOSS 至少各带 1 个削韧性的行动，
> 否则"连续两回合被打才破防"永远不会发生，这条规则等于死条文。
> 破韧行动通常伤害偏低，它的作用是制造"这张卡要废一回合"的威胁，逼玩家换人、抬血或提前防御。

### 12.2 意图预告

| 项 | 规则 |
|---|---|
| 时机 | 每回合开始时，公开敌方**本回合全部行动** |
| 范围 | **全部敌人**都提前 **1 回合**完整预告，行动数不限（BOSS 3–8 动也照单全摊） |
| 内容 | 图标（攻击 / 增幅 / debuff / 支援）+ 目标 + **伤害档位（低 / 中 / 高）**，不显示精确数值 |
| 蓄力 | 显示"蓄力中"，并标明下回合释放的技能名 |
| 标记 | 标红「无法打断」（§10.4） |

> 这是打断、破甲、开罐三条决策的**信息基础**。没有它，打断只是盲赌，破甲也无从选时机。
> 兰斯10 也是把敌人意图摊开来给你看的 —— 难度来自"知道了也得取舍"，不是来自"猜不到"。

### 12.3 关卡评价（不做硬性回合上限）

| 层 | 条件 | 通常是哪类队 |
|---|---|---|
| **通关** | 打赢即过，主线推进**不看回合数** | 所有人，轮椅队也能推完主线 |
| **★1 速通** | 回合数 ≤ 该关基准值的 60% | 爆发 / 平刀队 |
| **★2 无伤** | 全程无人被 down | 控场 / 坦克队 |
| **★3 高效** | 全程 AP 消耗 ≤ 基准值的 80% | 精算 build |

> 星数只影响**额外材料掉率**，不影响主线推进。这就是"轮椅可以，但拿不到所有奖励"的落点：
> 不去做回合上限惩罚慢队，而是把奖励拆成三个彼此冲突的星级 ——
> DOT 队能过关、能拿 ★2，但永远拿不到 ★1。
> 于是 DOT 队是"一种选择"，不是"最优解"。

### 12.4 路线式大副本（v1.1 预留）

**第一版仍做章节制，但结构按"大副本"预留** —— 章节本质上就是一条单线路由，
v1.1 把它扩成有分支的路线图即可，不需要推倒重写。

| 项 | 规则 |
|---|---|
| 重玩 | **卡池永不清空**。大副本可反复进入，星级取历史最高 |
| 难度曲线 | 首次进入卡池弱，只能走主路线；养起来之后才走得了困难路线 |
| **困难路线的门槛** | **按路线逐条手调**，不套全局公式 —— 门槛本身就是关卡设计的一部分 |
| **奖励差异** | 普通路线：材料 / 金币；困难路线：**专属非战力奖励**（签名材料、卡背、称号、剧情碎片、外观） |
| 恢复点 | 每 3–6 步一个（AP 满 / 血量 +30% / 支援重置）；章节制阶段放在章末 |
| 分支 | 短线硬 BOSS / 长线多补给，路线本身就是评价的区分条件 |
| 0→3 AP | 路线制下成立：**每段路线限一次**（到恢复点为止） |

> **重玩价值 ≠ 多周目重开。** 玩家辛苦收集的卡永远不会被扔 ——
> 这也正是经济系统不用为"周目赠送"重算的原因：没有重置，就没有额外的资源投放。
> 困难路线给的是**评价 + 专属的非战力奖励**，不是战力必需品，所以它不逼肝，
> 只是给养成的卡一个宣泄口。
>
> **门槛与掉落的粒度交给关卡设计**：哪条路线该多难、该掉什么，是逐条手调的，
> 不存在一个"总战力 X 就能进"的全局公式 —— 那会把路线图变成一张数值表。

**BOSS 的定位**

| 项 | 规则 |
|---|---|
| 行动数 | 3 – 4 个，且不重复同一模板（不会连续两次高额攻击） |
| down 威胁 | 高额攻击带 down（§7.3），**两个刺客都不一定扛得住** |
| 支援互动 | 会用第 7、8 条（加支援 / 拆支援） |
| 应对 | 玩家必须同时准备：防 down、清支援、开罐（防御档位） |

> BOSS 不是"数值更大的小怪"，是"每回合逼你做 3 个以上决策的东西"。
> 如果一队里没有坦克、没有治疗、没有破甲，那它就该打不过 —— 这是职业系统存在的理由。

### 14.2 调参指标

| 指标 | 健康区间 | 异常含义 |
|---|---|---|
| 平均 Combo | 5 – 8 | > 9 = 滚雪球过强，降封顶 |
| AP 溢出率 | < 20% | 高 = AP 上限太低或技能费太低 |
| **防御指令使用率** | 每场 0.5 – 2 次 | = 0 = 防御没用；> 3 = 敌人太痛 |
