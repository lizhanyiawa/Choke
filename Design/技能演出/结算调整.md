# 技能演出涉及的结算调整

## 游侠主动

| 技能 | 调整 | 原因与核对 |
| --- | --- | --- |
| 并头箭 | 原先是偏移 18 的两条平行窄带。改成以原朝向左右各转 15° 的两条窄带。每条仍长 305、宽 32、伤害 0.71 D。 | 设计要求分叉且近处可以叠中。回放核对重叠目标会吃到两次 0.71 D。 |
| 滑铲发箭 | 滑步后从实际落点起箭，施放后 0.30 秒结算。滑步距离、目标范围和 1.25 D 沿用。 | 给滑步和出箭各留可见一拍。核对箭的起点等于移动终点，命中前标靶血量无变化。 |
| 折线箭 | 第二段从与首段同一时刻改为首段命中后 0.18 秒，需有首段命中记录。伤害与择敌半径沿用。 | 折线的起点取首段真实接触位置，折返接力有独立到达帧。首段未命中时跳过第二段。 |
| 追星雨 | 三拍以单位实时位置为圆心。目标退场时，后续落点取它退场的坐标。三拍间隔和每拍 0.54 D 沿用。 | 核对标靶在三拍之间主动移动，以及最后坐标与历史命中坐标不同的情况。 |
| 裂景 | 原先给外环内敌人直接加 0.40 D。现在外环实际命中的位置在 0.14 秒后各炸出半径 55 的范围。同一敌人至多吃一次 0.40 D。 | 让地面裂点对应真实站位，聚堆会扩散，散开可躲掉额外伤害。核对两个次爆重叠处只扣一次附加伤害。 |
| 跟锋 | 首发从友卡身侧出手，0.22 秒后结算 0.46 D。9 秒接力条件、追击伤害和射程沿用。 | 让友卡和敌人之间的弹道可见，首发与随后真正触发的跟枪分开。 |
| 掠边扫 | 直线命中改在 0.28 秒后，范围、伤害和向边线的推距沿用。 | 宽箭浪走完预警再结算，敌人可以用已就绪的移动离开判定带。 |

## 回放和结束

- 预览中的普通移动示例只传移动数据，追脚针和悬针的跟踪触发不额外带入示例击退。
- 对局结束时取消待结算的动作和预警，已经结算的长收尾播放到淡出。核对五角跳完成击杀后，星形收尾会正常消失。

## 游侠黄金搭配

| 技能 | 调整 | 原因与核对 |
| --- | --- | --- |
| 顺羽、哨羽、折线三点 | 分别在触发后 0.12、0.14、0.16 秒结算续段。顺羽用第一击的原方向与接触点，哨羽从预置点起，折线三点从第二击接触点起。 | 让续段轨迹各自有起点和到达帧。单招与队友回放都由技能和被动自然触发。 |
| 反弧拒近 | 回程的 42 推距改用游侠当前位置定向。同一次归弧只执行这次位移。 | 这组搭配改变推向。避免基础归弧和黄金追加各推一次。 |
| 爆矢洄浪、封索回扣 | 以触发击退时记录的终点为圆心，0.26 秒后结算额外伤害。额外伤害按独立命中处理。 | 地面的洄浪和反扣在实际落点爆开，封索回扣只追加伤害。 |
| 绕点截路 | 慢区锚在第二轮实际作用区的圆心，持续 2.8 秒。 | 斜纹与实际慢区重合，结算回放核对区内移动速度下降。 |
| 跟锋护返 | 跟枪由队友实际 Q 命中触发。友引发盾，黄金为受盾者附上一次 35% 抗推，8 秒内有效。 | 实测首次 100 推距减为 65，抗推随后消耗。 |

## 召唤师回放

- 七档各 5 招主动。35 招分别在单招和队友场景核对了实体数量、实际交互、退场和清理，并在浏览器核对了七档分镜的条目及退场帧。
- 钉哨和绳偶的交互帧取敌人实际被拦停的时刻。三拍纸阵与星兽合奏的分镜取最后一座实体第一次生效的时刻，预览站位让三拍各有目标。
- 援尾偶与回旋桥的示例先演救护，再演回场接应。14 组黄金搭配均在单招和队友场景实跑到触发。
- 35 招主动的接触画面使用本体坐标、实际接触点和已结算的位移终点。只有哨偶和镜手走弹道到达结算，其余按部署物的行动或交互绘制。
- 对局结束时，场上的召唤物与其他收尾一同淡出。核对了重召替换、召唤师下场时召唤物继续留场，以及胜负确定后清理。

## 游侠被动

| 涉及技能 | 结算调整与原因 |
| --- | --- |
| 准手、稳瞄、侧移 | 准手与稳瞄只认单体主动。主动位移及被推后重新计站定。侧移只在普通移动到位后获得三秒远程减伤。 |
| 贴弦、移线、贴盾脚 | 贴弦在技能位移后记录首次直接命中，可在同一招后续段兑现。移线须确实向远离敌人的方向移动。贴盾脚由场内的护盾状态实时决定。 |
| 余折、脚针、悬光、跨队、瞄外、避前 | 余折只认折线箭第二跳。脚针和悬光由目标实际移动结束引发。跨队比较上一次普攻的目标。瞄外在选中界外目标时即时增加射程。避前比较移动前后与最近敌人的距离。 |
| 爆边、芯箭、坑缘、第二落点、偏锋、补射 | 读取实际地面外缘、轴心、延时或第二轮新命中。偏锋选实际命中组中离施法轴最侧的敌人。补射只认近身直接受击。 |
| 重落、返标、背弓、分眼 | 重落须由延时主动推出界，返标读取同招两次命中的间隔。传说池自身没有后撤技，背弓改由至少 90 的实际后撤移动起护。分眼只由己方主动击退留标。 |
| 追星边、次爆、压岸、扫边、星回、警戒、两目 | 追星边认同一目标第三拍，次爆只认本招此前未命中的敌人。压岸和扫边在朝最近边线的推击中加距。星回给首敌留九秒标记。警戒只在界内生效，两目按八秒触发间隔。 |
| 长弦势、镜痕、平轨、回星、断射 | 长弦势按实际线段方向判定最远命中。镜痕须由第二镜命中已中第一镜的敌人。平轨在第二条命中轨上取首敌。回星只由普通移动触发。断射的十秒增伤由主动命中兑现。 |

同一个事件可以分别触发多张卡装备的同名被动。预览中用同一套命中、移动、射程和冷却规则逐项回放，待用标记读取真实的增益、护盾和事件监听。超时会淡出，兑现时按实际命中或位移播放。

## 召唤师被动与黄金搭配

| 涉及技能 | 结算调整与原因 |
| --- | --- |
| 哨声双点 | 哨偶首发命中位置 120 内有另一敌人时，由哨偶实际位置补发一弹，0.20 秒后对仍在场的目标结算 0.37 D。没有第二个目标时不补发。 |
| 余纸 | 召唤组自然到期或最后一只被拆时准备下次普攻射程。用新组替换旧组不发放。 |
| 纸裂、纸替炸尾 | 纸裂由纸替身确实给友卡发盾触发。黄金搭配直接听纸替身被拆，以碎裂位置为圆心，在 128 内独立发放 3 秒移速。 |
| 离偶、补位、退阵 | 离偶和补位分别核对一次普通移动前后的近偶范围，击退、回场和范围内走动不触发。退阵按最近一只活着的己方召唤物判定。守偶、靠偶、退阵和覆轨的标记会随距离或召唤物退场解除。 |
| 影跟 | 影纸的追加推距确实生效时才为召唤师补血。 |
| 纸跟 | 在首次有效纸卫施盾前给基础 16% H 增加 5% H，合成一次 21% H 的结算和护盾数字。 |
| 双弦端点 | 第三次实际扫线时，以两只在场弦机的本体分别画半径 68 的作用圈，各自结算命中。 |
| 镜手改角、折纸缘 | 镜手改角以镜手实际发射方向定左侧推向。多体部署分别记录破损的实体，折纸缘仍受被动触发间隔限制。 |
| 投甲回 | 投甲兽成功发盾后给受盾卡一次 23% 抗推，与兽自身的 28% 区域抗推取较高值。区域抗推生效时保留这次待用抗推。 |
| 合奏回席 | 攻兽命中且护兽实际发盾之后，推兽的有效击退从推兽所在位置给 100 内的友卡尝试补 11% H 盾。用原有的护盾覆盖规则，护甲分支只画向实际拿到盾的卡。 |

已发放的限时护盾和增益按各自时限存续或在消耗时结束。七档 56 个被动和 14 组黄金搭配均在单招与队友场景核对了开启和禁用时的实际差异，并在浏览器查看触发、持续和收尾。待用效果另外核对了普攻、移动或受击时的消耗帧。
