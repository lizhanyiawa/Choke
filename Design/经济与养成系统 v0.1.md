# Choke! 经济与养成系统 v0.1

> 状态：草案。**所有数值均为起点值**，需用实测数据回填（见 §13 调参指标）。
> 配套文档：`抽卡规则 v0.1.txt`、`前端 Brain Storming.txt`。
> 假设规模：DAU 500，卡池 100,000 张，每包 5 张。

---

## 0. 设计原则

### 0.1 四层分层

把"卡"拆成四种东西，任何改动都要先问"它属于哪一层"：

| 层 | 内容 | 供给 | 定位 |
|---|---|---|---|
| 燃料 | C / UC / R / E | 海量（挂机主力） | 分解成碎片，喂养成 |
| 商品 | L / B | 中低（日周月常） | 市场流通，价格贴回收价 |
| 资产 | U | 极低（无损概率尾） | 收藏，长期溢价 |
| 工时 | 等级 / 命座 / 阀门 | 系统配额 | 永远绑定，不可交易 |

### 0.2 三条铁律

1. **凡是改变"下一季配速"的东西，必须绑定**（体力、阀门、保底产物、挂机卡）。
2. **凡是商品，才允许交易**（概率抽出的非保底卡、金币）。
3. **保底产出绝不进入市场**。可交易资产只能来自"无保底的纯概率尾"。

### 0.3 核心循环

```
体力 ──→ 副本 ──→ 金币 / 模组 / 进阶材料
  │
  └─→ 抽卡包 ──→ 卡片 ──┬─→ 分解 ──→ 品质碎片 ──→ 强化 / 兑换 / 命座
                        ├─→ 上架 ──→ 金币（玩家间转移，非系统发行）
                        └─→ 命座 / 强化 ──→ 战力 ──→ PVE 通关 ──→ 更多资源
```

关键：**金币的发行只来自系统（任务 + 副本），卡片永远换成碎片，不换成金币。**
否则 10,600 张/月/人的产量会直接冲垮货币。

## 2. 体力系统

### 2.1 恢复与上限

| 项 | 数值 |
|---|---|
| 恢复速率 | 1 点 / 6 分钟（240 / 天） |
| 自然上限 | 240 |
| 溢出处理 | 超出 240 后不再恢复；可手动领取「溢出体力」，1 点 → 3 金币 |
| 金币购买 | 60 金币 → 60 体力，每日 2 次（+120 体力/天） |

**每日可用体力 = 240 + 120 = 360**（强度党上限）。

### 2.2 体力去处

| 副本 | 体力 | 产出 |
|---|---|---|
| 金币本 | 30 | 80 金币 |
| 模组本 | 40 | 1 个 MOD + 20 模组材料 |
| 进阶材料本 | 30 | 3 份当阶进阶材料 |
| 活动本（赛季） | 20 | 赛季点数 |

### 2.3 典型分配（每日 360 体力）

| 用途 | 体力 | 次数 | 日产出 |
|---|---|---|---|
| 金币本 | 120 | 4 | 320 金币 |
| 模组本 | 120 | 3 | 3 MOD + 60 材料 |
| 进阶材料本 | 120 | 4 | 12 份材料 |

> 体力**不可交易**。它是纯工时资源，任何可交易的体力都会变成代练与脚本入口。

> 挂机池本质上只提供 C/UC/R/E，即"碎片矿"。

### 3.3 保底机制

| 项 | 规则 |
|---|---|
| 触发条件 | 连续 60 抽未出 L 及以上 |
| 保底产物 | 当期限定池 **三选一**，**绑定** |
| 保底计数 | 日 / 周 / 月常共享；挂机不计入 |
| 期望触发率 | 约 8%（自然 L 率已接近保底线，保底主要是兜底） |
| 月均保底次数 | 440 / 60 ≈ 7 次 |

**保底产物必须绑定。** 否则等于每两个月给全服发放一批可交易资产，参考游戏就是这么崩的。

### 3.4 镜像卡（本体卡的重复体）

本体卡是每个玩家唯一的 No.1 卡，绑定、不可交易、可无限喂养。
它**无法重复抽取**，所以升级材料必须另设通道：

| 项 | 规则 |
|---|---|
| 名称 | 镜像卡（Mirror） |
| 卡池 | 独立镜像池，**仅含全服玩家的本体卡**（500 张） |
| 获取 | 每开 1 包，**3% 额外掉落 1 张镜像卡**（不占 5 张配额） |
| 是否可交易 | **是** |
| 月产出 | 440 × 3% ≈ **13 张 / 人 / 月** |
| 全服月产出 | 6,500 张，摊到 500 张本体卡 ≈ **13 张 / 卡 / 月** |

因为镜像池只有 500 张，供给被精确控制。玩家**不需要自己抽到自己的卡**——靠市场买。
按 8 命座 + 4 段强化 ≈ 12 张需求，**两三周可凑满一张**。这就是市场存在的意义。

### 3.5 签名卡池（赛季限定）

| 项 | 数值 |
|---|---|
| 单抽 | 5 张，800 金币 |
| 十连 | 50 张，7,600 金币（5% 折扣） |
| 单抽概率（每张） | U 0.5 / B 3 / L 10 / E 32 / R 40 / UC 14.5 |
| 保底 A | 60 抽内必出 B+ |
| 保底 B | 10 抽内必出 L+ |
| 稀释 | **不稀释**，只出签名卡与材料，不出普通卡 |

> 参考游戏的签名池混入非签名卡，在 500 DAU 规模下只会放大挫败感，不建议照抄。
> 签名卡**可交易**，是赛季的主要市场商品。

## 5. 市场系统

### 5.1 结构

| 项 | 规则 |
|---|---|
| 形式 | 双边订单簿（买单 + 卖单），挂单价即成交价 |
| 求购 | **必须做**。本体卡只有 1 个买家，没有求购单就找不到人 |
| 搜索 | 精确卡名 / 卡 ID，不做模糊推荐 |
| 上架税 | 2%（挂单时扣） |
| 成交税 | 5%（成交时扣） |
| 挂单期 | 7 天自动下架 |
| 价格带 | 以 7 日成交均价为基准，**±40%**，超出无法挂单 |
| 限池 | 只允许交易**当期池 + 上一期池**；老卡只能自用 / 分解 |
| NPС 回收 | 分解值的 **70%**，每日限 **30 张** |

### 5.2 三条保护

1. **地板**：NPC 回收价 → 市场价格永远跌不破。
2. **缓降**：±40% 价格带 → 单日砸盘无法成立。
3. **供给隔离**：挂机卡、保底卡全部绑定 → 市场供给只由 440 包/月控制。

### 5.3 限池交易的必要性

10 万 SKU × 500 人 = 平均每张卡 0.005 个买家。这不是市场，是博物馆。
**只开放当期 + 上一期，等于把可交易池压到 2,000–3,000 张**，流动性才够。

## 8. 卡牌数值模型

### 8.1 基础值

```
基础值 = 品质基础 × (1 + 0.06 × (等级 - 1)) × 职业系数 × (1 + 命座加成)
```

| 稀有度 | ATK 基础 | 职业系数区间 |
|---|---|---|
| C | 40 | 0.8 – 1.2 |
| UC | 60 | 0.8 – 1.2 |
| R | 90 | 0.85 – 1.15 |
| E | 140 | 0.85 – 1.15 |
| L | 220 | 0.9 – 1.1 |
| B | 350 | 0.9 – 1.1 |
| U | 550 | 1.0（标准化） |

命座加成：每级 +3%，满 8 命 = +24%。

### 8.2 随机性放在哪

**建议：基础值不随机，随机性全部放在 MOD 与技能。**

理由：基础值随机会让"同一张卡"价值分叉，10 万卡池 × 随机基础值 = 数值不可控，PVE 难度曲线无法设计。MOD 已经承担了"刷词条"的爽感，不需要再叠一层。

### 8.3 本体卡的无限强化

满 8 命 + lv80 后，继续喂镜像卡 → 在指定属性上获得微小加成。

| 规则 | 数值 |
|---|---|
| 单次加成 | 指定属性 +0.3% |
| 第 n 次喂卡成本 | **n 张镜像卡**（成本递增） |
| 次数上限 | 无 |
| 生效范围 | **仅 PVE**；PVP 用标准化数值 |

成本递增让"无限"自然收敛：n=5 需要 15 张 ≈ 1 个月；n=10 需要 55 张 ≈ 3.7 个月。
不需要硬上限，市场自己会封顶。

## 9. PVE 模式

### 9.1 主线（抄兰斯10的骨架）

抄的是**"有限回合 + 自由攻略顺序 + 不可逆损失"**，不是战斗系统本身。

| 项 | 数值 |
|---|---|
| 章节 | 8 章 × 12 关 = 96 关 |
| 章节解锁 | 前 3 章线性；第 4 章起自由选择顺序 |
| 回合限制 | 每章 10 回合，每回合只能执行 1 个行动 |
| 不可逆 | 章节通关后该章资源锁定，无法回刷 |
| 敌方战力 | 第 n 章 = 基础战力 × 1.15^n |

**战斗自动化程度：高。** 玩家决策在编队 / 路线 / 资源分配，不在临场操作。
理由：10 万张卡不可能逐张手工设计技能，PVE 必须走模板化。

### 9.2 周本

| 难度 | 敌方战力 | 阀门掉落 | 金币 | 碎片 |
|---|---|---|---|---|
| 1 | 1.0× | 2 | 200 | 500 |
| 2 | 1.3× | 2 | 400 | 900 |
| 3 | 1.7× | 2 | 700 | 1,500 |
| 4 | 2.2× | 1 + 掉落 | 1,100 | 2,400 |
| 5 | 2.8× | 1 + 掉落 | 1,600 | 3,600 |

每周阀门总量 **8 个**（难度 1–3 各 2 个 + 4–5 额外 2 个，按首通计）。
阀门**赛季结束作废**，不允许囤积。

### 9.3 赛季

| 项 | 数值 |
|---|---|
| 周期 | 30 天 |
| 内容 | 赛季关卡 20 关 + 赛季周本 + 赛季商店 |
| 产出 | 赛季点数（兑换签名池券 / 材料 / 外观） |
| 结算奖励 | 抽卡券（**下季生效**）+ 称号 + 卡背 + 入场动画 |
| 数值奖励 | 仅作用于 **PVE 面**，不进入 PVP |

### 9.4 "非唯一解"的三层设计

1. **属性克制环**：雷 / 火 / 冰 / 物理，克制 +30%，被克 -20%。
2. **关卡机制**：每 4 关插入 1 个特殊关（限回合 / 禁某关键词 / 限职业 / 限费用）。
3. **弱点标签**：每个 BOSS 给 2–3 个弱点标签，**至少 2 套 build 可以通关**。

保证手段：每关通关数据回收后，若某套 build 占比 > 70%，即认定该关设计失败，调整机制。

## 10. 进度限制（阀门与赛季）

### 10.1 阀门

| 项 | 规则 |
|---|---|
| 周上限 | 8 个 |
| 用途 | lv40+ 每段消耗 2 个 |
| 赛季结束 | **作废**，或按 **≤30% 折算**成通用命座碎片 |
| 是否可交易 | 否 |

> 阀门**永远不能原样退回**。能原样退回的东西会被囤积，下赛季开局直接爆闸。

### 10.2 赛季卡退役

| 项 | 规则 |
|---|---|
| 构建材料（lv40+ 用的那部分） | 赛季结束退回 **70–80%**，绑定 |
| 阀门 | **不退**，只允许 ≤30% 折算 |
| 理由 | 材料是沉没成本，可退；阀门是配速器，不可退 |

> 材料不要退 100%。全额退会把强化变成"押金"，玩家无脑拉满，阶梯需求被自己填平。

## 13. 调参指标（上线后每周看）

| 指标 | 健康区间 | 异常含义 |

| 金币总存量 | 稳定或缓升 | 持续快涨 = 沉没点不足 |

| 阀门使用率 | > 80% | 低于 50% = 周本吸引力不足 |
