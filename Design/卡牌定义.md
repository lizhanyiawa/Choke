# 卡牌定义

## 分两层

| 层 | 内容 | 变不变 |
|---|---|---|
| **CardDef** | 身份、稀有度、职业、技能、编号、玩家信息 | 静态，可热更 |
| **实例状态** | 等级、命座、MOD、装备 | 每个玩家每张卡不同 |

运行时把 CardDef + 实例状态合成 `CardFaceData`，卡面组件只吃合成后的结果。

## CardDef

```ts
interface CardDef {
  id: string                 // pool-{osuId} / hero-{osuId} / custom-{uuid}
  osuId: number | null       // 玩家卡对应的 osu! id；手工卡 null
  name: string
  rarity: Rarity             // C / UC / R / E / L / Radiant / Prismatic
  job: Job                   // tank / warrior / mage / support
  no: number                 // 卡面编号
  total: number              // 编号分母
  country?: string
  globalRank?: number | null
  pp?: number | null
  profileUrl?: string
  art?: string               // 头像地址，浏览器随看随载
  banner?: string            // 主页封面地址
  skills: CardSkill[]        // 1–3 个
  version: number            // 定义版本
}
```

`CardSkill`：

```ts
interface CardSkill {
  name: string
  element: Element           // 金木土冰火雷光暗物
  ap: number
  mp?: number
  passive?: boolean
}
```

## 运行时状态

```ts
interface CardState {
  level: number              // 1–80
  constellation: number      // 0–6 / 本体卡 0–12
  mods: Mod[]                // 最多 3 个装槽
}
```

`faceFromDef(def, state)` 合成 `CardFaceData`，`CardFace` 渲染。

## 导出

`/pool-lab` 的「导出卡定义」按钮：

- 读入 Mutualify / osu 同步数据
- 按稀有度公式分池
- 每张卡转成 `CardDefRow`（`version` 省略，批量时统一）
- 下载 `choke-cards.json`

单卡调试用 `/card-editor`，导出的是完整 `CardFaceData`，可以用 `defFromFace` 转成 `CardDef`。

## 数据库映射

后面建 `cards` 表时，字段一一对应：

```sql
CREATE TABLE cards (
  id          text PRIMARY KEY,
  osu_id      bigint UNIQUE,
  name        text NOT NULL,
  rarity      text NOT NULL,
  job         text NOT NULL,
  no          integer NOT NULL,
  total       integer NOT NULL,
  country     text,
  global_rank integer,
  pp          numeric,
  profile_url text,
  art         text,
  banner      text,
  skills      jsonb NOT NULL,
  version     integer NOT NULL DEFAULT 1
);
```

实例表只存 `card_id + level + constellation + mods`，不复制定义。

## 版本

- `version` 只在定义字段变化时加一
- 实例表存 `card_version`，读的时候按版本取定义
- 卡池导出时 `version` 统一，热更时按 `id` upsert
