# Choke 客户端基础

2026-11-10 对照了 osu!gacha 首页导航、市场和图鉴入口，并用公开 FAQ 复核规则。现场能核对导航，市场和图鉴的明细区没有返回内容。下表的交易机制以 FAQ 为准。 [首页](https://osugacha.com/) · [市场入口](https://osugacha.com/market) · [公开 FAQ](https://osugacha.com/about)

| 模块 | osu!gacha 基础设施 | Choke 对应入口 |
| --- | --- | --- |
| 账号 | osu! 绑定、个人身份、账号等级和功能解锁 | 账号、osu! 登录、个人编号、金币和精华 |
| 获取 | 免费卡包、用 Stars 获取其他卡包、独立卡池 | 牌桌发卡包、开包、卡池、背包库存 |
| 收藏与检索 | 自有卡牌、图鉴、玩家池分开浏览 | 卡册和图鉴按玩家名查找。图鉴支持稀有度、地区、收集状态和排序 |
| 队伍和培养 | 队伍、卡牌培养、Mod、卡牌锁定 | 卡组、卡牌详情、现有培养入口 |
| 流通 | 固定价购买、限时拍卖、直接交易。可流通对象包括卡牌、Mod 和材料 | 固定价市场。搜索、筛选、分页、上架、购买、下架和重新上架 |
| 战斗 | 队伍入口、深渊、塔、谱面、领域和 PvP | 战斗准备、实队出战与演练、场上反馈、战斗结果 |
| 进度与服务 | 日常及周期任务、等级奖励、公会、反馈与帮助、音效入口 | 对照表中的独立模块 |

Windows 上双击 `Choke.exe` 启动游戏。客户端使用 WebView2 绘制界面。F11 切换全屏，Esc 返回，Ctrl+F 聚焦搜索。

排版取自 lazer 选歌的操作顺序。筛选靠上，左侧聚焦一个对象，右侧连续浏览；上下键移动选中行，选中块的斜切底板向右伸出。战斗按中央敌人、两侧信息、下方队伍和操作条组织，血量变化、出手、受击、防御和结果就地反馈。 [lazer 选歌界面实拍与分区](https://osu.ppy.sh/community/forums/topics/2221264) · [选歌轮播设计提交](https://github.com/ppy/osu/pull/31542)
