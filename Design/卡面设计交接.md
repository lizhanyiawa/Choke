# 卡面设计交接

## 项目

osu! 同人卡牌游戏 Choke! 的玩家卡。2:3 竖版，同一组件在 100 / 140 / 220 / 380 / 560px 下复用。

## 代码位置

| 文件 | 内容 |
|---|---|
| `src/card/CardFace.tsx` | 卡面组件 |
| `src/card/card-face.css` | 全部样式 |
| `src/card/types.ts` | `CardFaceData` |
| `src/card/data.ts` | 七档 Demo 卡 |
| `src/pool/face.ts` | 池卡转卡面 |
| `src/pool/*` | 卡池、稀有度、同步脚本 |

## 预览

```bash
npm run dev
# 380px 单卡
http://localhost:5173/card-lab?solo=4&w=380
# 带布局参考线
http://localhost:5173/card-lab?solo=4&w=560&guides=1
```

`solo` 是 `DEMO_CARDS` 的下标：0 C / 1 UC / 2 R / 3 E / 4 L / 5 Radiant / 6 Prismatic。

## 当前结构

四个分区，从上到下：

```
[header]   深蓝块 + 白色名字卡（LEGENDARY / Lv / 名字 / 国家排名 pp / MOD）
[art]      深色插画 + 多层描边 + 底部命座条
[skills]   三条胶囊（深色外圈 + 白色内条 + 金色 AP）
[foot]     深蓝块（职业圆 / BP / 编号 / 白色品牌缺口）
```

## 设计约束

- 所有内部尺寸用 `cqw`，卡宽 = 100cqw，卡高 = 150cqw
- 字体用 Outfit（`--font-heading`），**不要换衬线**
- 七档稀有度靠三样识别：外框渐变、`--panel` 面板色、`--accent` 强调色
- 色板变量定义在 `.cf`，七档在 `.cf[data-rarity="..."]` 里覆盖
- 组件不要依赖后端，卡面只吃 `CardFaceData`

## 目标视觉（参考图的核心特征）

```
┌─────────────────────────────┐
│ 深蓝头部                     │
│  [金徽章] ┌白卡──────────┐   │
│           │ LEGENDARY Lv │   │
│           │ Mrekk        │   │
│           │ AU #1 pp MOD │   │
│           └──────────────┘   │
├─────────────────────────────┤
│ 多层描边插画                  │
│  深蓝→白→深蓝→金→深蓝         │
│                             │
│ 深蓝命座条 + 白色凹槽 + 星    │
├─────────────────────────────┤
│ 深蓝胶囊 + 白色胶囊 + AP      │
├─────────────────────────────┤
│ 深蓝底部块                   │
│ ⚔ BP: 5,783      ID         │
│    ╭─ Choke! Series ─╮      │
└─────────────────────────────┘
```

关键点：

1. **分区要清楚**：四块之间靠颜色和圆角分开，不是靠线
2. **头部白卡贴边**：白卡应从徽章右侧一直顶到深蓝块的右沿和下沿，只留左侧/左下圆角
3. **插画是多层描边**：不是单线，至少 4 层，层与层之间有色带
4. **命座条是凹槽**：深蓝条上挖一个白色圆角缺口，星星在缺口里
5. **底部是独立块**：品牌条是块底的一个白色缺口，不是横穿的白带

## 已完成

- 七档 `--panel` / `--accent` 色板
- 插画多层 inset 描边 + 内侧渐变线
- 头部合并成深蓝块 + 白卡
- 技能双层胶囊
- 命座条深蓝 + 白色凹槽
- 底部深蓝块 + 品牌标签
- `?guides=1` 布局参考线（红=安全区，蓝=模块，黄=元素，竖线=中心）

## 未解决

| 问题 | 现状 | 期望 |
|---|---|---|
| 头部白卡没贴边 | 四周都有深蓝留白 | 右侧/下沿贴住深蓝块，只留左下圆角 |
| 底部品牌条 | 白色圆角标签，72% 宽 | 更像块底缺口，不要横穿 |
| 命座凹槽形状 | 矩形 + 上圆角 | 两侧有台阶/斜切 |
| 插画占位 | 判定圈 + 滑条 | 真实卡用 `a.ppy.sh/{id}` 头像或 banner |
| 小尺寸 | 100px 下文字隐藏 | 可接受，但白卡/深蓝比例要检查 |

## 验收标准

- 560px 下四块分区一眼能分出来
- 左右留白对称，参考线红框内不溢出
- 100px 下不糊、不爆版
- 七档只看颜色也能区分

## 不要做

- 不要换掉 cqw 体系
- 不要动 `src/pool/` 的稀有度公式和数据同步
- 不要把 `CardFace` 改成依赖网络请求
