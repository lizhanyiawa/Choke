# 界面动效与音效 v0.1

这份文档记录 `feat/ui-polish` 这一轮对界面、动画、音效做的改动，以及以后加新界面时要遵守的约定。
只动了前端展示层：`packages/shared`（战斗规则）、`apps/api`、`content/` 都没有改。

## 1. 约定

### 1.1 音效

入口只有一个：`import { playSfx } from "@/audio/sfx"`。

```ts
playSfx("deal")                                   // 立刻响
playSfx("deal", { rate: 1.1, volume: 0.7 })       // 调音高、音量
playSfx("deal", { delay: 0.3 })                   // 0.3 秒后响（排在音频时钟上，不占 JS 定时器）
```

- **任何按钮都有声音，不用自己写。** `src/audio/ui-sfx.ts` 在 `document` 上监听点击：按钮 / 链接默认 `click`，`role="tab"` 是 `tab`，复选框是 `toggle`，下拉框改值是 `tick`。
- **专属音效优先。** 点击处理里自己调过 `playSfx` 的，这一下不会再叠默认音。所以不要到处写 `playSfx("click")`，只在有更贴切的声音时才写。
- **声明式换音 / 消音**：在元素或它的祖先上写 `data-sfx="open"`（指定音名）或 `data-sfx="none"`（不出默认音，用于成败各有专属音效的按钮）。
- 一串相同的声音（发牌、落地）用 `delay` 错开，并让 `rate` 逐个升高，不要同一帧叠十声。
- 页面还没被点过时浏览器会挂起音频；这期间的声音直接丢弃，不会攒到第一次点击时一起响。

这一轮新增的音名（全部是合成音，不依赖 `public/sfx/`）：

| 用途 | 音名 |
|---|---|
| 界面 | `hover` `open` `close` `tab` `toggle` `notify` `claim` `send` `whoosh` `deal` `stamp` |
| 战斗 | `select` `ap` `start` `warn` `laser` `buff` `debuff` `star` |

`buff` / `debuff` 已经做好但还没有调用点：引擎目前不发「上状态」事件，等事件有了再接。

### 1.2 动效

- 共用的时长、曲线、关键帧在 `src/ui/motion.css`（`App.tsx` 全局引入）：`--ui-fast/base/slow`、`--ui-ease-out/in/spring`，`ui-fade-in/out`、`ui-pop-in/out`、`ui-rise-in`、`ui-slide-in-left/right`、`ui-stamp-in`、`ui-shake`、`ui-bump`。
- 弹层要有离场动画时用 `src/ui/usePresence.ts`：`const { mounted, leaving } = usePresence(open, 170)`，样式里用 `.is-leaving` 播离场。
- 只动 `transform` / `opacity`。循环动画只放在很小的元素上。
- 每个新动画都要在 `@media (prefers-reduced-motion: reduce)` 里关掉。
- 想让一段内容「换了就重新播一次入场」，给节点一个随内容变化的 `key`（战斗底栏的战况、邮件正文、流水列表都是这么做的）。

### 1.3 观感

沿用桌面的做法：按钮用实色底边表示厚度，按下时下沉。战斗控件和加载页也使用 `book.css` 的 `--bk-*`，跟随桌面的亮暗主题。战区保留属性色和警戒色。

## 3. 战斗

### 两版战斗界面

| 入口 | 准备与战斗布局 |
|---|---|
| `/battle?ui=classic`（首次默认） | 左侧大号 VS 与敌名斜带相交，右侧两条 WARNING 夹住「准备战斗」。开战后用折线血条，双方支援分列两侧。 |
| `/battle?ui=modern` | 顶栏放工具和回合数，中间是敌人与打击区，招式和战况进入独立播报条，下方留给卡牌与指令。 |

准备和战斗中都能按右上的「新版界面」或「经典界面」切换，切换时响 `toggle`。`BattlePage.tsx` 持有本场状态和操作记录，切换保留关卡、回合与血量。浏览器用 `choke:battle-ui` 记住选择，带 `ui` 的链接优先。

两套舞台分别在 `src/battle/view/` 和 `src/battle/view-modern/`，样式随各自舞台挂载和卸载。登录、加载与错误提示共用 `src/battle/battle-gate.css`。

战斗时直接点卡上的主动技能。技能、换人、防御和结束回合指令不通过 Tab 选择或 Enter / 空格触发。技能说明及新版「敌方下一步」说明跟随鼠标，优先放在光标右上方，靠边时换边。技能费用列在标题，AP 不足时只提示差额。说明不接管点击，也不替换战况文字。

两版速度按钮默认 `1×`，点击按 `1× → 2× → 4× → 0.5× → 1×` 循环。下一次动作以所选倍速播放：事件间隔为 `380 毫秒 / 倍速`，其中 `2×` 保留原常速的 190 毫秒间隔。切档不打断已开始的动作，也不改变单次回弹和受击红晕的时长。

战报默认关闭。经典版只留速度旁的「战报」按钮，打开后显示在战场左上角；现代版显示在左栏、敌方支援下方。战报内使用细灰粉滚动条，翻旧消息不滚页面；回到底部后继续跟随新消息。无需关掉战报即可出招、防御、换人或结束回合。

支援铭牌把拆除所需的「强度」与实时蓄力分开写。说明和技能提示一样跟随鼠标，靠边自动换侧；键盘聚焦时贴着铭牌显示。右侧铭牌的图标与文字镜像靠右。

技能、支援和状态说明共用战斗视口内的浮层，在独立讨伐页和远征全屏战斗中都显示在战斗画面上方。

**新增的演出**

- 准备画面入场：警戒带扫入 → VS 砸下 → 标题、目标面板、评价条件 → 卡一张张发下来。
- 开战 / 重开：鼓点 + 横扫全屏的 `BATTLE START`。
- 回合切换：压暗的带子从中间拉开，字从一侧冲进来、停住、冲出去；敌方回合反向、红色。
- 技能横幅：一条动画管进场和退场（原来只有进场，消失是硬切）；敌人出招是红色。
- 血条：每一段实际扣血时，只有受击方血条回弹；力度按本段净掉血 / 最大 HP 计算。暴击不额外放大血条震幅，连续命中重新起震，不叠加位移。实条先到位，残影稍后追上。
- 伤害数字：同时飘着几个就往两侧、往上错开，连击不再叠成一团；暴击 / 弱点用更重的砸落动画。
- 我方挨打：被点名的卡短促后坐；单段掉血达到队伍最大 HP 的 10% 时整排卡也后坐。新版打中敌人时背景与打击区一起回弹，经典版保留原有攻击演出。AP 和指令不随动。未掉血、治疗不震血条；系统开启「减少动态效果」时用局部高亮代替回弹。
- 受击红晕只在下半屏靠近底边淡入。连续扣血延长同一层红晕，最后一击后淡出，不逐段闪烁；各段命中由卡牌和血条的回弹表现。「减少动态效果」下不显示红晕。
- AP 宝石亮起时弹一下，悬停技能时将要花掉的几颗闪动；「行動終了」「DOWN」是盖章动画。
- 结算：等最后一击演完才出现；卡片落下，徽章、标题、说明依次出现，拿到的星一颗一颗盖上去（每颗一声 `star`），最后才是按钮。
- 替补席、战报、提示框、支援铭牌、状态签都有入场动画。

**修掉的问题**

- 经典版的讨伐目标列表可收起，两版都限制列表高度，超出的目标在面板内滚动。
- 压暗滤镜加在卡框上，把盖在上面的「行動終了」章也一起压暗。改成只压卡面。
- 我方挨打的数字后面跟着和数字一样大的招式名，盖住卡面。招式名缩成数字下面的小字。
- 登录 / 没卡 / 出错 / 加载这几个状态原来是不相干的深蓝卡片和裸文字，出错时没有回去的路。改成和舞台同色的卡片，都带「回桌面」。
- 连着两次出招时，前一条横幅的定时器会把后一条提前收掉。
- `choke-battle.css` 原来没有 `prefers-reduced-motion`，已加。
- 7 张卡面的数据每次渲染都重建，悬停、飘字都会让卡面重画；改成只在战斗状态变化时重算。

## 4. 开包与桌面

**开包**

| 节拍 | 画面 | 声音 |
|---|---|---|
| 大包飞到面前 | 原有 | `whoosh` |
| 撕开 | 原有 | `tear` |
| 卡从撕口抽出 | 原有（每张错开 70ms） | 每张一声 `deal`，音逐张升高 |
| 落成一摞 | 原有 | `thud` |
| 翻普通卡 | 原有 | `reveal-*`，连翻时一张比一张高 |
| E 以上蓄力、亮相 | 新增：卡下方砸出稀有度大字 | `charge` → `reveal-*` |
| L 以上亮相 | 新增：全屏闪光 + 冲击波 + 向外飞的火星；神话 / 彩虹牌桌震一下，彩虹火星一颗一色 | `reveal-l/radiant/prismatic` |
| 闪卡 | 原有 | 翻开后补一声 `shine` |
| 桌面结算 | 数量签、拖放框、按钮依次出现 | `success` / `levelup`（原有） |
| 扁平结算 | 最后一张归位后旧牌列淡出，结算面板同时淡入；底部「关闭」或「继续开包」 | 同上 |
| 全部放到桌面 | 原有 | `whoosh` + 每张落桌一声 `deal` |

手动逐张翻牌时，E 及以上卡牌蓄力、翻正后停在中央，不会自己归位。这段时间底部不显示任何按钮，只有提示条写出操作：蓄力或翻正中按空格 / 点卡面跳过，停住后点卡面或按空格收起。最后一张也停了再结算。「全部翻开」仍自动播放，不需要逐张确认。

「跳过动画」模式原来是五张卡直接出现、没有任何声音：现在卡一张张翻着拍到页面上，E 以上外圈亮一下稀有度颜色，配 `tear` → `deal` ×5 → 按最好那张收尾。

扁平页的「跳过动画」直接显示结算；系统开启「减少动态效果」时，翻牌结束后不再播放结算过渡。

**桌面**

- 拿起：`lift`，越重越沉（卡 < 卡包 < 物件）。放下：卡 `deal`、卡包 `drop`、物件 `thud`。
- 东西落进卡册 / 背包：落地时补一声 `thud`。
- 发牌按钮：卡包甩下来 `whoosh`，落桌 `thud`。
- 快速收卡：一串 `deal`；重置桌面：`whoosh`。
- 取消静音时响一声，听得到「开了」；静音图标换成矢量图标（原来是 emoji）。
- **修了一个错位 bug**：`.desk-stage` 是 `overflow: hidden`，合着的抽屉有一截在它下沿之外，点物件打开书时焦点移动会把整个桌面滚上去 54px，之后所有物件都错位。改成 `overflow: clip`。

**没验证到的**

- **声音没有用耳朵听过。** 无头浏览器没有扬声器，只能确认「这一下有声音被排出去」。19 个新合成音的音色、音量平衡需要真人听一遍再调；`/sfx-lab` 目前只列有录音样本的音名，新音名不在里面。
- 神话 / 彩虹档的开包演出没有实抽到：本地测试库里没有 Mythic 档的卡，服务端抽到这一档会直接报错。传奇档实抽验证过，更高两档只是同一套演出换颜色和加震动。
- 没有在真机、低端机、Firefox / Safari 上测。
