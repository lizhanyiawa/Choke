# 扁平界面设计 v0.1

这份文档记录扁平界面（`src/flat/`）现在长什么样、怎么进、怎么和原来的桌面共存，以及往里加新页面时要遵守的约定。
线框和设计稿图因为画着已取消的功能（体力、日常任务、挂机包等），已暂时移除，原图在 PR #8 的历史提交里。以这份文档和代码为准。

## 1. 它是什么

- 一套和桌面并排的界面：左边侧栏（窄屏换成底部标签）、上面顶栏、中间是普通的页面。不拖东西，不翻书。
- 桌面没有被替换。两套界面用同一个账号、同一批接口，玩家随时能换。
- 只给走完新手引导的玩家用。登录、新手礼包、新手引导都还在桌面上。
- 开包、卡册、卡组、图鉴、背包、市场和远征都在扁平界面里。账号和副本仍从新版入口整页跳到原来的桌面。
- 原桌面里的 NPC 回收、本体卡吞噬镜像及功能锁提示仍在桌面和卡册里。
- 桌面上没有的功能直接做在这里。现在有成就和签到（`/quests`）、商店（`/shop`）、补给箱（`/supply`）和远征（`/expedition`）。

## 2. 地址和切换

| 地址 | 进哪里 |
|---|---|
| `/` | 扁平首页（未完成登录、礼包、引导的玩家回 `/home`） |
| `/expedition`、`/packs`、`/supply`、`/cards`、`/deck`、`/codex`、`/backpack`、`/quests`、`/shop`、`/market`、`/more` | 扁平界面的独立页面 |
| `/home`、`/home?panel=…` | 原桌面「家园」，可直达旧面板 |
| `/desk`、`/desk?panel=…`、`/?panel=…` | 兼容旧地址，转成 `/home` 并保留参数与锚点；`/intro` 和 `/gacha` 也转回家园 |
| `/home?bind=…`、旧 `/?bind=…` | osu! 绑定回跳，打开原账号面板，读取后清掉绑定参数 |

- 桌面顶栏的「回新版」（走完引导才出现）去 `/`。扁平侧栏、头像菜单和手机「更多」里的「家园」去 `/home`；不再用本机偏好决定默认入口。
- 桌面顶栏还有「成就」和「商店」（也是走完引导才出现）：整页跳到 `/quests`、`/shop`，不改设置。这两页只在扁平界面里有；桌面账号面板里原有的签到和一键领取照旧。
- 两套界面之间一律整页跳转。扁平界面里面换页走 History API，不重新加载（`src/flat/router.ts` 的 `navigate`、`src/flat/Link.tsx`）。
- 进门检查（`FlatApp`）：没登录、没领新手礼包、引导没走完，都 `location.replace("/home")`。
  引导走没走完要等服务端那份进度（`useProgressSynced`），不信本机缓存：换了浏览器缓存是空的，会把老玩家误送回桌面。
  账号取失败或进度 8 秒取不回来时，加载页给「重试」和「回原来的桌面」。
- 登录页、教学战的「回桌面」去 `/home`。从新版卡组进练习战，返回 `/deck`；从远征页进入的战斗是全屏覆盖层，继续后回到地图。

## 3. 导航

导航表只有一份：`src/flat/nav-items.ts`。侧栏、底部标签、「更多」页都从它取。

| 入口 | 去向 | 备注 |
|---|---|---|
| 首页 | `/` | |
| 远征 | `/expedition` | 扁平界面内换页 |
| 开包 | `/packs` | 角标是手上的卡包总数 |
| 补给箱 | `/supply` | 角标是现在有没有可领的（可领 / 已满）；页面规则见《补给箱前端对接清单》 |
| 卡册 | `/cards` | 底部标签上叫「卡牌」 |
| 卡组 | `/deck` | |
| 成就 | `/quests` | 角标是现在能领几样（绿色）；`quests` 解锁（Lv.3） |
| 商店 | `/shop` | 不设解锁条件，入口不上锁 |
| 图鉴 | `/codex` | |
| 市场 | `/market` | 没绑定 osu! 也能浏览；买卖按解锁表校验 |
| 背包 | `/backpack` | 也能从开包页进 |
| 账号 | `/home?panel=account` | 只在「更多」页和头像菜单里 |
| 家园 | `/home` | 侧栏最下面，副标题「原来的桌面」 |

- 侧栏（宽度 ≥ 900px）：首页、远征、开包、补给箱、卡册、卡组、成就、商店、图鉴；分隔线；市场、背包；最下面是家园。
- 底部标签（宽度 < 900px）：首页、远征、开包、卡牌、更多。最多五个，其余都在「更多」页（`/more`）。
  「卡牌」进入卡册；卡册、卡组和图鉴共用页内导航，底栏都点亮「卡牌」。补给箱、成就、商店、市场、背包归到「更多」；有可领取事项时亮绿点。
- 有解锁条件的入口（导航项的 `feature`）没解锁时是锁着的：侧栏角标写还差什么（`Lv.3`、`未绑定`、`未解锁`），「更多」页的卡片上写整句原因；点了只弹提示，不跳转。
  判断和文案都来自 `content/unlocks.json`（`featureLockHint` / `featureLockTag`，在 `src/tutorial/unlocks.ts`），和服务端拒绝时给的是同一句。

## 4. 顶栏

从左到右：等级条、金币、精华、邮箱、头像。体力已经取消，顶栏不再有体力。

- 等级条和邮箱直接用桌面的组件（`LevelMeter`、`MailBox`）。
- **头像菜单**：账号、配色（亮 / 暗）、音效（开 / 静音）、家园、退出登录。
- 弹层点到外面或按 Esc 关闭。窄屏时弹层贴在顶栏下面。
- 窄屏的顶栏只留图标和数字。

## 5. 页面

### 5.1 首页（`/`）

卡片在 `src/flat/home/`。
宽屏两栏：左栏是远征和「今日」，右栏是卡包、今日推荐谱面、下一个解锁；卡组横贯整行。
窄屏排成一列：远征、卡包、今日、推荐谱面、卡组、下一个解锁。

- **远征**（`ExpeditionCard`）：读 `GET /expeditions/current`。
  - 有没结束的远征：进行中还是已保存退出、还剩多久、地图名、队伍血量、已得几星、已攒下的奖励，按钮是「继续远征」（已经走到终点时写「去结算」），壳内进入远征页。
  - 没有：只有「去远征」。
  - 结算和放弃留在远征页做（确认、结算画面都在那里），首页不放。
  - 倒计时到 0 时重取一次（服务端读的时候顺便做到期结算）；取回来已经没有了，就把等级条对一次（到期结算的玩家经验是直接加的）。
- **今日**（`TodayCard`）：和成就页读同一份总览、用同一套领取动作。`quests` 没解锁时只写锁的原因。
  - 页头：「全部成就」去成就页，一直贴着标题；有东西可以领时右边是「一键领取 N 项」。
  - 这几天的签到（今天前面四天、今天、后面两天；月初月底不够就顺着挪）和「签到」。
  - 成就最多三条：可以领的在前，其次是离完成最近的，领过的不列。每条只有名字、进度的数字和「领取」或「前往」（`QuestRow` 的 `compact`）。全领完了换成一句话。
- **卡包**：每种卡包还有几包，「开包」进 `/packs`。
- **补给箱**（`SupplyCard`）：离线攒下的物资和「领取」，详见《补给箱前端对接清单》。
- **今日推荐谱面**：任务页那一张卡（见 5.2），今天没有谱面时不出现。
- **下一个解锁**：离现在最近的那一级开什么功能、还差多少经验；全部解锁后不显示。市场卡在没绑定 osu! 上时单独提一句并给「去绑定」。
- **我的卡组**：七张真实卡面、n/7、总战力，「编辑卡组」进 `/deck`。窄屏折成 4 + 3。
- **粉色主按钮给谁**：有没结束的远征 → 「继续远征」；否则手上有卡包 → 「开包」；否则 → 「去远征」。
  远征和卡包都取回来之前谁都不是粉色，免得主按钮先亮在一处又跳到另一处。主按钮在远征卡上时这张卡描粉边。签到和领取用绿色。

### 5.2 成就（`/quests`）

代码在 `src/flat/quests/`，接口见《任务前端对接清单 v0.1》。
`quests` 没解锁（Lv.3）时整页只有一句锁的原因，不发请求。日常、周常、月常任务和活跃度宝箱已经取消，页面上没有。

- **页头**：分类页签（全部，加服务端给的 `group` 分栏），页签上的绿色数字是这一栏有几样可以领；右边是「一键领取 N 项」。
- **成就列表**：名字、说明、奖励、进度条，右边是「领取」「已领」或「前往」。
  - 可以领的排最前，其次是进行中的（离完成越近越靠前），已领的沉底。成就按 `group` 分栏。
  - 「前往」去哪由任务的 `event` 决定（`QuestRow.tsx` 的 `QUEST_GOAL`；每种事件都要写一行，漏了编译不过）：
    开包类去 `/packs`，养卡类去 `/cards`，市场类去 `/market`，远征类去远征页；
    签到和推荐谱面留在本页，滚到右栏那张卡；玩家等级没有「前往」。
  - 列表下面固定一行说明：成就不会过期。
- **签到卡**（右栏；窄屏排在页签上面）：本月月历、今天和下一个特别日子的奖励、「签到」。
  - 月历七格一行，只是排版，不对星期。签过的打绿勾，今天描粉，有特别奖励的日子描金，漏签的调暗。漏签不能补。
  - 窄屏先只露出今天所在的那一行，点「看整月」展开。
- **今日推荐谱面卡**（`OsuDailyCard`，自己取数据，首页也用这一张）：谱面名、通过条件、「去 osu! 打」（新标签页）、「检查成绩」。
  - 检查之后按钮上倒数冷却。通过后换成「今天已通过」。通过目前没有奖励，以后只发外观或成就。
  - 没绑定 osu! 时换成「去绑定」。今天没有谱面、或者取不到时，整张卡不出现。
- **领取和签到**共用一个「正在进行」：同一时间只做一件事，别的领取按钮先禁用（推荐谱面卡上的检查自己管自己的）。
  做完用提示条写拿到了什么，然后把成就总览、金币、卡包、等级一起对一遍。
  服务端说界面上的状态过时了（`already_claimed`、`not_done`、`already_signed`、`not_found`），提示之后重新取一次。
- **成就总览只有一份**（`quests/store.ts` 的 `useQuests`），侧栏角标、「更多」页、成就页和首页的「今日」卡共用。
  服务端不推送：谁改了数据谁调 `refreshQuests()`。进成就页和首页时对一次表。
- 倒计时按服务器的钟走：取数据时记下服务器的 `now` 和本机时间差多少。

### 5.3 商店（`/shop`）

代码在 `src/flat/shop/`，接口见《养成与经济前端对接清单 v0.1》第 9 节。
商店不设解锁条件（对接清单的要求），页面和导航入口都不做解锁检查。

- **页头**：标题、一句「买到的东西都是绑定的，不进市场」，右边是钱包条：手上有的碎片、商品要用到的碎片（没有也列出来，写 0）。金币在顶栏，这里不重复。
- **三段货架**，按商品的 `section` 分：日常补给（`supply`）、碎片博弈（`gamble`）、碎片保底（`pity`）。没有商品的那一段不显示。
  每段标题右边写什么时候重置、还有多久（取这一段第一件商品的 `nextResetAt`）。
- **商品卡**：名字、限购（今日 1/2、本周 3/10）、说明、能拿到什么、价格、数量、「购买」。
  - 固定产出列成小签；博弈箱列概率表，概率按接口给的权重现算（`weight` ÷ 全部 `weight` 之和，留一位小数），不写死。
  - 数量从 1 到「10 和还剩几次里小的那个」，选了几件价格就写几件的总价；只剩 1 次时不显示数量。
  - 买不了时按钮禁用，下面写原因，只说第一条：金币不够、哪种碎片不够。
  - 卖完的整张调暗，按钮换成「已售罄」。
  - 买成之后卡片底下留一行「获得：…」（博弈箱开出了什么看这一行），留到这件商品下一次购买或离开页面。
- **购买**：同一时间只放一笔出去，期间全页的购买按钮都停用。
  - 买成：用回包里的限购和钱包直接换上，不重新取货架；提示条写买到了什么；金币对一次，有卡包就对卡包。
  - 没买成：提示服务端的原话。`shop_limit_reached`、`not_enough_coins`、`not_enough_items`、`unknown_shop_item` 说明页面上的东西过期了，货架重新取一次；`not_enough_coins` 再对一次金币。
- 货架取不回来：第一次显示报错和「重试」；手上已经有货架时（到点重取、对账重取）先留着旧的。

### 5.4 倒计时和到点重取

共用的东西在 `src/flat/ui/time.ts`。

- 每秒走一格的秒表（`useNow(1000)`）放在最小的那个组件里，整页不跟着每秒重画。
- 数据到点会过期的页面（现在是商店货架）放一个 `<RefetchWhenDue dueAt refetch skew? />`：到点重取一次。
  取回来的还是旧的一轮（请求失败了，或者本机的钟走快了）就过 30 秒再取，之后每次翻倍，最长隔 10 分钟。
- 到点了、新一轮还没取回来的那一会儿，页面上写「正在重置」「正在换新一轮」，不停在「0 秒」。
- 任务接口带服务器时间，倒计时按服务器的钟走（`skew`）；货架接口不带，按本机的钟走。

### 5.5 市场（`/market`）

- 「在售」按玩家名、品质和卡牌类型在服务端筛选分页，可按上架时间或价格排序。公共卡与镜像卡分开筛选、定价和查询成交记录。同名卡的详情展示实际在售实例。
- 「我的挂单」（`/market?view=own`）列出仍在售的挂单。详情显示到期时间；下架前确认退回的押金，上架税不退。
- 购买前显示售价、购买后余额和该种卡的成交参考。不允许买自己的挂单；未绑定 osu! 的已毕业账号可以浏览，但不能上架或购买。
- 「去卡册上架」进入 `/cards?mode=list`，选卡时显示类型和发行序号，点卡直接到「交易 / 处置」。上架前显示适用的价格带、2% 上架税和 5% 押金。成交税、7 天有效期和限制见《养成与经济前端对接清单》§5。
- 家园旧市场仍可用（`/home?panel=market`），买卖共用同一份数据。

### 5.6 远征（`/expedition`）

远征是扁平界面的一页，共用侧栏、顶栏和底部标签；实现位于 `src/flat/expedition/`。未完成的远征在大厅横幅里继续、结算或放弃，不再弹旧版的进入确认框。

- 大厅按主线、日常、周常和赛季筛图；地图卡显示卡池张数、战斗场数、星级、目标和通关次数。锁定图显示原因。进行中的远征横幅显示状态、倒计时、步数、星数、威胁、队伍血量和已攒奖励。
- 出征准备分配上场卡槽、AP 上限和稀有度权限点数，再从卡册挑选卡池。开始前确认锁定卡牌规则；远征不消耗体力。
- 每个战斗节点先选择上场阵容，再进入原战斗舞台；战斗继续、同步队列和重放仍使用共用战斗引擎。战斗离开未同步操作前会要求确认。
- 进入路线页默认聚焦当前位置，不自动打开详情；「全图」切换到路线全览，「当前位置」回到聚焦视角。点击节点才打开详情，不会移动。详情展示服务端公开的遭遇、事件选项、剧情与奖励确定时机；只有当前节点可执行事件、剧情或战斗，只有已处理节点的可达后继节点出现「前往下一站」。地图支持缩放和平移。
- 地图右下保留途中已攒奖励；底部单行并排展示完整出征卡面，窄屏可横滑。每张卡下的血条均显示同一个队伍 `hpRatio`，不重复卡名、职业和稀有度。
- 结算展示结束原因、星级、目标完成情况和奖励。结算或放弃后同步钱包、卡包、玩家进度、任务和地图记录。
- 宽屏详情悬浮在选中节点旁，不改变地图宽度或镜头；碰到地图下沿时优先上移。窄屏详情悬浮在地图底部。仅正文滚动，标题和关闭按钮固定。样式类名前缀为 `xp-`，支持减少动态效果；窄屏准备页可折叠配置。

## 6. 页面能拿到什么

页面用 `useFlat()`（`src/flat/context.ts`）。能进到页面里，说明已经登录、领过礼包、走完引导。

| 字段 | 说明 |
|---|---|
| `user`、`progress` | 账号（金币、精华、道具库存、本体卡）和等级进度 |
| `packs`、`packError` | 各卡池的卡包数与库存读取错误；库存未取回是 `null` |
| `notify(text, kind?)` | 页面底部的提示条。`kind` 决定音效；错误停 4 秒，其余按字数停 1.8–6 秒 |
| `refreshUser()` | 金币、精华变了之后调 |
| `refreshPacks()` | 卡包数量变了之后调 |
| `setPacks(counts)` | 用开包的回包同步库存与所有入口 |
| `logout()` | |

玩家经验变了调 `refreshProgress()`（`src/tutorial/store.ts`）。
任务总览不在 `useFlat()` 里：用 `useQuests()`（`src/flat/quests/store.ts`），改了数据之后调同一个文件的 `refreshQuests()`。补给箱同理，用 `src/flat/supply/store.ts` 的 `useSupply()` 和 `refreshSupply()`。

## 7. 视觉规则

沿用桌面那一套，不另起配色：

- 颜色用 `--d-*`（`desk.css`）和 `--bk-*`（`book.css`），外壳自己的几样在 `.flat-app` 上（`--fl-bg`、`--fl-rail`、`--fl-btn`、`--fl-info`）。亮色写在 `.light .flat-app`。
- 桌面端（视口宽度 ≥1200px）扁平界面整体放大约 20%，主区页面宽度上限为 1040 CSS px（放大前）；手机端保持原布局。
- 窗口较矮时，首页缩短模块间距和卡组槽位，宽度允许时让摘要并排，尽量在首屏显示完整的七个槽位。高度不足时保留滚动，不裁切内容。
- 页面的根是 `fl-page`，模块是 `fl-card`（纸色底加一道细线，里面不再套带边框的盒子）。去别处的文字链接用 `fl-link`。
- 每屏只有一个粉色主按钮（`bk-btn--main`）。
- 「可以领」用绿色（`--bk-good`，按钮是 `fl-claim`）；进度和数值用青色（`--fl-info`）。
- 品质的颜色只出现在卡面和碎片的色点上。
- 导航的选中态是淡粉底加一道粉线，不用实心粉。
- 文案用中文短句，不放装饰性的英文小标签。
- 动效用 `src/ui/motion.css` 的 `--ui-fast`、`--ui-base`、`--ui-ease-out`，并照顾 `prefers-reduced-motion`。
  进场动画（关键帧只写了 `from`、没有延迟的那种）不要加 `both`：放完之后元素上会一直挂着一个 transform，单独成层，WebKit 里页面别处再变时会留下没擦掉的旧画面。

## 8. 加一个新页面

1. `src/flat/router.ts` 的 `FLAT_ROUTES` 加地址（只有一段）。
2. `src/flat/FlatApp.tsx` 的 `PAGES` 加组件。
3. `src/flat/nav-items.ts` 把对应入口的 `href` 换成 `route`；有解锁条件的写 `feature`。
4. 页面自己的样式放在页面旁边，类名用页面自己的前缀，不改 `fl-*`。

## 10. 卡牌与卡包页面

电脑和手机、亮色和暗色都用同一套页面；实际使用服务端数据与共用卡面。

| 页面 | 地址 | 交互 |
|---|---|---|
| 开包 | `/packs` | 选包、查单张概率。最后一张归位后，翻牌区与结算交叉淡入淡出；跳过动画直接结算。底部可关闭或继续开同类卡包。 |
| 卡册 | `/cards` | 实例卡册；名称、类型、国家 / 地区、职业、闪卡、品质和排序由服务端筛选分页。点卡打开原养成详情。分解、NPC 回收可跨页选卡，先核对并预览，确认后才移除。 |
| 卡组 | `/deck` | 七槽主卡组；候选区与卡册共用筛选、多行卡格和分页，默认按 pp 排序。选槽、换位与保存规则不变；至少上阵一张才进入练习战。 |
| 图鉴 | `/codex` | 按公共卡定义统计持有，不重复计算实例。已收集的卡展示最近一张持有实例的实际技能；只读详情另外能展开该职业与品质可能抽到的技能。未收集的卡没有固定技能配置。 |
| 背包 | `/backpack` | 查卡包、碎片、经验池；「去开」带 `?pool=…` 到开包页，神秘卡包复用原问卷领取本体卡。 |

- 桌面端（≥1200px）按 1:1 渲染，不再整体放大。首页正好一屏：上面两栏按内容高，卡组卡占剩下的高度，卡面随高度缩放（最宽 1180px，≥1600px 为 1380px）；窗口矮到放不下时才出现滚动条。卡册先定行数（每行 6 张，最多 4 行，卡面不小于 150px），再让卡宽去适配剩余高度，卡宽上限 210px；矮窗口降到 1 行。手机每页 9 张。
- 卡组宽屏：上方「七个竖版卡槽 + 右侧汇总栏（已上阵、总战力、保存状态、清空）」；下方「筛选 + 六列候选（每页 12 张）」和右侧吸顶预览。预览里「上阵/替换/交换」按钮在卡面上方，首屏可见。候选卡只预览，确认后才上阵；手机保留原槽位操作弹层和每页 9 张候选。
- 卡组候选卡用惰性静态头像缩略图；详情、卡册和开包保留完整卡面。翻页保留当前槽位和旧卡格，暂不可选卡，末页保留分页位置。
- 桌面图鉴使用六列卡格，分页独立在网格下方；矮窗口允许页面滚动，不裁卡或分页。
- 新版卡牌直接入册，没有拖卡到桌面或「全部放到桌面」。额外获得的镜像卡在结算展示，不插入原来的逐张翻牌演出。
- 原桌面的取包、拖放、开包结算、引导和面板照旧。开包概率、每日额度、养成解锁和上阵规则以服务端为准。
